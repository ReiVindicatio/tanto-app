# T020 学習記録のエクスポート／インポート

- 状態：設計レビュー
- マイルストーン：M1 基盤
- 優先度：高
- 依存：
- 更新：2026-10-18

## 目的・背景

- 今の学習記録は localStorage だけ。ブラウザのデータを消すと失われ、端末をまたげない
- ログイン・同期（T003）までのつなぎ、同期後のバックアップ、名寄せ（T005）で肢 ID が変わるときの付け替えに使う
- T003 で「サーバーには回答ログだけを置き、FSRS は回答ログから再計算する」と決めた。**ところが今は回答ごとの記録（ログ）を残していない**（肢ごとの集計と FSRS の状態だけ）

## 設計

### 1. 回答ログの記録を始める（学習記録の形の追加）

- 新しいキー `tanto.log.v1`：回答1回ごとに1件を追記する（消さない・書き換えない）

```json
[{ "s": "yobi-2026-minpo-q01-a", "ok": true, "at": "2026-10-18T12:34:56.789Z" }]
```

- `s`：肢 ID、`ok`：正解したか、`at`：回答した日時（ISO）。肢カードで答えたときに追記する（今の `recordAnswer`・`review` と同じ場所）
- 容量：1件およそ60バイト。1万回答で約0.6MB（localStorage の上限はおよそ5MB）。上限に近づいたら警告する（実装は簡単な確認だけ）
- **既存の記録は消さない。**今ある集計（`tanto.history.v1`）と FSRS の状態（`tanto.srs.v1`）はそのまま使い続ける。ログは T020 の実装以降の回答から貯まる（過去の回答はログに戻せない）

### 2. 書き出し（エクスポート）

- ホームの下に「学習記録」の欄を置き、「ファイルに書き出す」ボタンで JSON をダウンロードする
- ファイル名：`tanto-records-YYYYMMDD-HHmm.json`

```json
{
  "format": "tanto-records",
  "version": 1,
  "exported_at": "2026-10-18T12:34:56.789Z",
  "log": [ … ],
  "history": { "<肢ID>": { "attempts": 3, "correct": 2, "last": true, "at": "…" } },
  "srs": { "<肢ID>": { FSRS のカード状態 } },
  "srs_new": { "minpo:2026-10-18": 20 }
}
```

- 欄には、回答ログの件数・回答済みの肢の数・最後に書き出した日時（`tanto.lastExport`）を表示する。書き出してから7日以上たっていたら、書き出しを促す一言を出す

### 3. 読み込み（インポート）

- 「ファイルから読み込む」でファイルを選ぶ → 中身を確かめて、件数を見せて確認 → **統合**する（上書きはしない）
- 確かめること：`format` が `tanto-records`、`version` が 1。違えば読み込まずにメッセージを出す
- 統合のしかた

| データ | 統合のしかた | 理由 |
|---|---|---|
| 回答ログ | 和集合。同じ肢・同じ日時の重複は1件にする | 追記だけなので衝突しない |
| 肢ごとの集計 | 肢ごとに、最後の回答（`at`）が新しいほうを採る | 同じ端末のバックアップを読み直しても二重に数えないため。2台で別々に解いた回数は合算されない（T003 で回答ログから数え直せばよい） |
| FSRS の状態 | 肢ごとに、最後の復習（`last_review`）が新しいほうを採る | 新しい状態のほうが今の記憶に近い |
| 新規の導入数 | 科目・日付ごとに大きいほう | |

- 読み込む直前の状態を `tanto.backup.beforeImport` に保存しておく（読み込みを誤ったときに戻せるように。戻す画面は作らず、必要なら手で戻す）

### 4. コードの置き場

- `app/src/records.ts`：書き出し・読み込み・統合の処理を、画面から切り離した関数にする（T001 で単体テストを書けるように）
- `app/src/history.ts`：回答ログへの追記を足す
- `App.tsx`：ホームの「学習記録」の欄

### 5. 確認のしかた（T001 がまだないので）

- headless Chrome で：ブラウザA（記録あり）で書き出す → 記録のないブラウザBで読み込む → ホームの回答済み数・今日の復習の期限数がAと同じになる
- 同じファイルを2回読み込んでも、件数が増えない
- 形式の違うファイルを読み込むと、拒否される

## 設計で決めてほしいこと

1. 回答ログ `tanto.log.v1` を今から記録し始めてよいか（学習記録の形の追加）
2. 読み込みは「統合」だけでよいか（「上書き」は作らない）
3. 「書き出してから7日以上たったら促す」の一言はあってよいか

## 完了条件

- 書き出したファイルを別のブラウザで読み込むと、履歴と復習の状態が再現される
- 同じファイルを2回読み込んでも二重にならない
- 回答ログが記録されている（T003 で使う）
- `docs/features.md` を更新している
