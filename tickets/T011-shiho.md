### 提案（Claude）

1. **名寄せを入れる（T005 の案A）**。本文が同じ（空白・全角半角・句読点をならす）で、出題時点の○×も同じ肢を1枚のカードにまとめる
   - 回答ログは今までどおり出典の肢 ID で記録し、読み込み時に「出典の肢 ID → カード ID」の対応表で読み替える（ログは書き換えない。決定011の約束どおり）
   - カード ID は予備の肢 ID（すでに公開・回答の記録がある）にする
   - ○×が食い違う組はまとめずに止める（パースの誤りか、出題の違い）
   - 肢カードの画面に出典を全部出す（「予備 R06 第3問イ／司法 R06 第5問ア」）
   - 「年度を選んで解く」では、その年度の肢として出す（司法 R06 を解けば重なる肢も出る）。復習・今日の○問・まちがえた肢では1枚
2. **画面**：科目の画面に「予備／司法」の切り替えを置き、年度の一覧を分ける。今日の○問・科目ごとの進み具合は両方を合わせる（名寄せ後の枚数）
3. 進め方：errata の確認が終わったら、名寄せ（データの対応表＋アプリの読み替え）→ 画面 → 書き出し、の順に1つのチケットで入れる
