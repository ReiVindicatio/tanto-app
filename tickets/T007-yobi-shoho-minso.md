### パーサの直し（止まった原因）

| 原因 | 年度 | 直し |
|---|---|---|
| 問の見出しの括弧が半角（「(配点：２）」「（配点：２)」） | 商法 H24・H28 | 全角・半角のどちらも読む |
| 配点が見出しの次の行に分かれている | 商法 H30 第20問 | 次の行の配点も読む。問の行範囲を見出しの行から数える |
| 正答表の備考「順不同」の「同」が右段の欄に入る | R01（商法・民訴の4問） | 数字でない語は、一番近い段の**備考欄**に入れる（前回は一番近い列の段に入れていた）。民法部分の正答データは変化なし |
| 「幾つかの立場がある」の「幾つ」で個数問題と誤判定 | 商法 H30 問30 | 個数問題は「幾つあるか」「の個数」に限る |
| 「誤ったものを組み合わせた」の向きを取りこぼし | 商法 H30 問25 | 「誤ったもの」「誤りであるもの」「正しくないもの」も誤りの向きとして読む（影響はこの問だけ） |
| 解答欄の表記の崩れ（「［№37］［， №38］」） | 民訴 H23 問34 | 「［，」を許す |
| ア・イ（・ウ）が事例や判決で、それを説明した選択肢から1つ選ぶ形 | 民訴 H23 問38・H24 問40・H26 問42/43・R03 問32 | **新しい形式 `meta_choice`**（問題カード。選択肢の範囲で採点） |
| 【記述】の見出しなしで【事例】の直後に肢が続く | 民訴 R08 問31 | 前提文の中で、リード文が予告する最初の肢ラベル（「１から５までの各記述」なら１）が出たら肢に切り替える |

- 形式を足したこと（`meta_choice`）はデータの値の追加で、スキーマ（欄）は変えていない。問題カードとして扱い、肢の○×は導出しない
