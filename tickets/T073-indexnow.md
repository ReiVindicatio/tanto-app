# T073 IndexNow で Bing などに URL を知らせる

- 状態：完了
- マイルストーン：M3 公開
- 優先度：中
- 依存：T072
- 更新：2026-11-07

## 目的・背景

T072 のあとも、Google のサイトマップは「取得できませんでした」のまま（最終読み込み日時は空。まだ読みに来ていない）。Bing Webmaster Tools には登録済みだが、URL はサイトマップ任せ。IndexNow は URL を検索エンジンへ直接知らせる仕組みで、Bing（と、その結果を使う DuckDuckGo など）に効く。Google は IndexNow を使わない。

## 議論（決まったこと）

2026-11-07、ユーザーが「鍵のファイルを `public/` に置き、URL を送るコマンドを足す」案に OK（外部サービスを使うので、設計はこの説明で合意を取った）。無料で、Google Cloud のクレジットは使わない。

## 設計

- 鍵：`app/public/<鍵>.txt`（中身は鍵だけ）。秘密ではない（公開して、サイトの持ち主であることを示す仕組み）。鍵の値は `app/scripts/indexnow.mjs` の `KEY`
- `node scripts/indexnow.mjs`：本番の `/sitemap.xml`（目次）と子のサイトマップから URL を集め、`https://api.indexnow.org/indexnow` へ送る（1回 10,000 件まで）。本番に鍵がなければ止まる。`--dry-run` は件数だけ、`--since YYYY-MM-DD` は更新日がその日以降の URL だけ
- 自動では流さない。初回に全件、以後は解説を足して配信したあとに `--since` で送る（全件を何度も送らない）
- テスト：E2E `pages.spec.ts` に、鍵のファイルが配信されることと、サイトマップの目次から URL と更新日を読めること

## 完了条件

- 3つのテストが通る
- push して配信のあと、全件を送って 200 か 202 が返る
- 数日後に Bing Webmaster Tools でインデックスの数を見る（ユーザー）

## 結果（完了時）

- 実装（2026-11-07）：鍵 `app/public/07361959c353627dd086ea76929a436e.txt`、`app/scripts/indexnow.mjs`。本番のサイトマップから 3,219 件を数えられる（`--dry-run`）
- テスト：パイプラインの回帰・単体、vitest 178、E2E 91、e2e:sync 8、worker の型、すべて通過
- ついでに直したテスト：`e2e/listen.spec.ts` の聞き流しのテストが、全体で流すと2回続けて落ちた。単独なら10回とも通る。3肢目に入ってから「止める」までに、テスト用の短い音声で3肢目を聞き終えることがあり、「聞いた 2 肢」が 3 になる。確かめたいのは「答えた 1 肢」だけを記録することなので、聞いた数は 2 か 3 で通すようにした（直したあと全体で3回とも通過）
