# T057 聞き流しモード（肢と○×・解説の結論を読み上げる）

- 状態：完了（設計レビュー OK：2026-10-24）
- マイルストーン：M2 拡充
- 優先度：中
- 依存：T056（エンドレスの読み足しを使う）
- 更新：2026-10-24

## 目的・背景

- 画面をじっと見られないとき（移動中・家事の間）にも過去問に触れたい。肢を読み上げ、少し待ってから○×と解説の結論を読む

## 議論（2026-10-24 決定）

- 制約：端末の読み上げ（Web Speech API の speechSynthesis）は、画面を消す・別のアプリに切り替えると止まる（特に iPhone）。画面は点けたまま使う（Wake Lock で勝手に消えないようにする）。画面を消しても聞けるようにするには全肢の音声ファイルを作って置く必要があり、外部の音声合成の費用と数GB の置き場所が要るのでやらない
- 記録：読み上げの間（○×を言う前）に画面の○×を押したときだけ、普段の回答と同じに記録する。押さなければ記録しない（復習の期限も累計も変えない）
- 読む範囲：肢 → 考える間（既定5秒）→「正解は、まる（ばつ）」→ 解説の結論の一文。解説の本文は読まない
- 入口：ホームの今日の○問の欄に「聞き流す」。範囲（全科目／科目）はそこで選んだもの、選び方は今日の○問と同じで、止めるまで続ける

## 設計

### 画面（`src/ListenPlayer.tsx`。/play で開く。PlaySession に `kind: "listen"` を足す）

- 今読んでいる肢の本文を大きく出し、いまの段階（読み上げ中／考える時間（残り秒）／正解）を出す
- 下に大きな ×・○。肢の読み上げ中と考える時間に押すと記録し、待たずに「正解」「不正解」と言ってから答えと結論を読む
- 操作：一時停止／再開、次へ（飛ばす）、止める。止めたら「聞いた N 肢・答えた M 肢・正解 K」を出して戻る
- 設定（端末に保存）：読む速さ（0.8／1.0／1.2／1.5）、考える間（3／5／8秒）
- 日本語の読み上げ音声がない端末では、その旨を出して始めない

### 読み上げ（`src/listen.ts`）

- speechSynthesis の日本語の声で読む。肢の末尾の解答欄の番号（［№11］）は読まない
- 読み間違えやすい語の読み替えの表（例：瑕疵→かし、競売→けいばい、○→まる、×→ばつ）。読み間違いに気づいたら表に足す
- 解説のない肢（民法の改正前など）は「この肢の解説はありません」

### 肢の選び方

- エンドレス（T056）と同じく、今日の○問の選び方で20問ずつ選び、残りが少なくなったら足す。聞いただけの肢は記録されないので、読み足しのときはこの回にすでに出した肢を全部除く（同じ肢を2度読まない）

### 記録

- 画面で○×を押したときだけ `recordAnswer`（普段の回答と同じ1件。形は変えない）

### テスト

- 単体：読み替えの表・解答欄の番号を除くこと
- E2E：speechSynthesis を作り物に差し替えて、読み上げ → 考える間 → 正解の流れ、○×を押すと記録されること、押さなければ記録されないこと、止めたら件数が出ること

## 完了条件

- ホームから聞き流しを始め、画面を点けたまま肢と○×・結論を聞き続けられる。押した○×だけが記録される

## 実装の記録

- `src/listen.ts`（読み替えの表・解答欄の番号を除く・長い文を句点／読点で区切る・日本語の声・Wake Lock）、`src/ListenPlayer.tsx`（画面と読み上げの流れ）、`startListen`（`src/play.ts`。エンドレスと同じ選び方を共有）
- 設計からの追加：前提文の要る肢・小問の肢は、肢だけ読んでも意味が通らないので聞き流しの対象から除く
- iPhone は押した操作の中で読み上げを始めないと声が出ないので、画面に「▶ 聞きはじめる」を置き、押したときに最初の（空の）読み上げをする
- 読み替えの表は最初は5語（瑕疵・競売・遺言（いごん）・○・×）。実機で読み間違いに気づいたら足す
- 実機（iPhone・Android）ではまだ試していない。E2E は読み上げを作り物に差し替えて流れだけ確かめた
- テスト：単体 `src/listen.test.ts`、E2E `e2e/listen.spec.ts`
