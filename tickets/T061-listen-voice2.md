# T061 聞き流しのアニメ風の声（声1・既定）

- 状態：実装中（設計レビュー OK：2026-10-26）
- マイルストーン：M2 拡充
- 優先度：中
- 依存：T058
- 更新：2026-10-26

## 目的・背景

- T058 の声（Chirp 3 HD・Achernar）は自然で聞きやすいが、落ち着いた読み上げで、聞いていてテンションが上がらない（ユーザー）
- 声優のような演技のある声（「知的で可愛い女の子の声・ささやき気味」）を、2つ目の声として選べるようにしたい

## 議論（2026-10-26 決定）

- 音声合成：Google の Gemini の音声合成（Agent Platform（旧 Vertex AI）の `gemini-3.8-flash-tts`）。読み方を言葉で指示できる。請求は Google Cloud の無料トライアルのクレジット（残り約45,000円・2027-01-24 まで）
  - AI Studio のキーは前払いのクレジットが切れていて使えない。Cloud TTS 経由の Gemini は権限の都合で使えず、Agent Platform を直接呼ぶ（キーは `.secrets/google-vertex-key`。サービスアカウントにひも付け、Agent Platform API だけに絞ったもの）
  - VOICEVOX・AivisSpeech は試さない（ユーザー）
- 声：見本を約20通り聞き比べて、**Leda（女性）＋「舌足らず」の指示**に決めた（`pipeline/tts_gemini.py` の `LEDA_PROMPT`）
- 実在の特定の人物（声優・Vtuber）の声には似せない。声の性格（高め・甘い・舌足らず・ささやき気味）を一般的な言葉で指示するだけ（パブリシティ権・公開できる状態を保つため。Gemini は出来合いの声に演技を付ける仕組みで、声色は声ごとに固定）
- 指示文は「台本の形」で渡す（日本語・英語の指示を文の前に置くと、指示まで読み上げた）

## 設計

### 音声を作る（`pipeline/`）

- `pipeline/tts.py --voice gemini-leda --workers 4`：今の声と同じ肢（17,246本・約132万字）を `audio/tts/gemini-leda/` に作る。manifest の sha256 は「指示文＋読む文」で取る（指示を変えたら全部作り直しになる。今の声の manifest は変わらない）
- 合成の処理は `pipeline/tts_gemini.py`（見本の `tts_gemini_sample.py` と共有）。返ってくる WAV／PCM を mp3（48kbps・モノラル）にする
- 押した答えの「正解。」「不正解。」も同じ声で作る（`public/sounds/gemini-leda/seikai.mp3`・`fuseikai.mp3`）
- `pipeline/tts_upload.py --voice gemini-leda`：R2 の `tts/gemini-leda/` に上げる（Worker の `/audio/*` はそのまま使える。声の名前の形に合っている）
- 2回読みの検出：同じ文を2回続けて読む失敗がある（100肢で3本）。今の声の同じ音声の1.8倍より長ければ作り直し（3回まで）、だめなら作らない（アプリは今の声で流す）
- 安全フィルター：性に関わる犯罪の肢は、Google の安全フィルターで止められることがある（100肢で1本：わいせつ物公然陳列罪）。作らず、今の声で流す
- 100肢（200本）で測った値（2026-10-26。先頭の司法 H23 の100肢）
  - 時間：4本ずつで7分 → 全部で約10時間
  - トークン：出力 110,889（音声1秒あたり約25）・入力 36,483（18,801字ぶん）→ 全部で出力 約780万・入力 約260万
  - 費用：Gemini 2.5 Flash の音声合成の単価（出力100万トークンあたり10ドル）なら約80ドル（約12,000円）。3.8 の単価は請求で確かめる（全部作る前に、最初の2,000本ほどで請求の額を見る）
  - 長さ：今の声の約1.2倍（ゆっくり読む指示のため）。容量 約2.2GB

### アプリ

- 聞き流しの設定（速さ・考える間）に「声」を足す：**声1**（Gemini・アニメ風。**既定**）／**声2**（T058 の Chirp 3 HD）。`ListenPrefs` に `voice` を足し、端末に覚える（localStorage。学習記録ではない）
  - 2026-10-26 ユーザー：呼び名は「声1／声2」。試し生成を聞いて「めちゃくちゃいい」ので、アニメ風を既定に、そして「声1」に（既定が声2なのは変）
- `audioUrls(cardId, part, voice)`・`clipUrl(name, voice)` で声ごとの置き場所を引く（パイプライン・R2 の名前は `gemini-leda` のまま）
- 声1の音声がない肢（作る前・失敗）は、声2の音声で流す。それもなければ端末の読み上げ（今の仕組み）
- 表示：声1のときは「音声：Google の Gemini の音声合成（作れなかった一部の肢は Google Cloud Text-to-Speech）で作成（AI 音声）」。読み間違いの注意書きはそのまま
- プライバシーポリシーは変えない（送るものはない）

### 先に言っておくこと

- 刑法の性に関わる肢など、安全フィルターで止められた肢は今の声で流れる（声が途中で替わる）
- 舌足らずの演技なので、今の声より法律の用語や数字が聞き取りにくいことがある。指示の演技は1本ごとに少し揺れる（全部同じ雰囲気になる保証はない）
- 解説を直したら、両方の声を作り直す（`tts.py` と `tts.py --voice gemini-leda`）。Gemini の声（声1）の作り直しはクレジット（トライアル終了後は有料）を使う
- R2 の保存は約2GB になる（無料枠 10GB の範囲）。Worker の呼び出しは声を変えても同じ数

### テスト

- 単体：`getListenPrefs` の声（既定・不正な値）、`audioUrls`／`clipUrl` の声ごとの URL
- E2E：既定は声1で声1の URL を取りに行く・声1がないときは声2に戻る・声2を選ぶと声2だけ
