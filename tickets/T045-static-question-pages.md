# T045 問ごとの静的ページ（検索で見つかるように）

- 状態：完了
- マイルストーン：M3 公開
- 優先度：高
- 依存：T044
- 更新：2026-10-21

## 目的・背景

アプリは JavaScript で画面を描き、URL もホーム・科目・マイページしかない。検索エンジンからは中身のないページに見えるので、「予備試験 令和5年 民法 第11問」のような検索で見つからない。

## 決まったこと（2026-10-21 ユーザー決定）

- 問ごとに、ふつうの HTML のページを作る（`/q/<問の ID>/`）。年度・科目ごとの一覧（`/q/<束の ID>/`）と入口（`/q/`）も作る
- 中身：問題文・前提・肢・選択肢。**公式の正解と解説は「正解と解説を見る」で折りたたむ**（解いてから見る）
- 各ページに、出典の表記・編集加工の記載・非公式であること・AI が生成した解説の表示を必ず入れる。古い年度には、アプリと同じ法改正の注意書きを出す
- 「アプリで解く」から科目の画面へ。前後の問へのリンク。名寄せした肢は「同じ肢」の出典へリンク
- 解説の誤りが人目に触れる機会が増えることは、ユーザーが承知のうえで決めた（AI 生成の免責を表示している）

## 設計

- `app/scripts/pages.mjs`：`npm run build` の最後に流し、`dist/data/*.json` から `dist/q/` と `dist/sitemap.xml` を書く。git には入れない（ビルドのたびに作る）
- 静的ファイルの配信は Workers の無料枠を使わない。ファイル数 約3,400（上限 20,000）、計 約46MB
- E2E：`e2e/pages.spec.ts`（問のページ・一覧からたどる・検索エンジン向け）

## 結果

- ✅ 問のページ 3,041・一覧 176・サイトマップ 3,220 URL
- テスト：パイプライン 33・単体 78・E2E 29 通過
