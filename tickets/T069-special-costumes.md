# T069 律の特別な衣装

- 状態：実装レビュー

- 優先度：中
- 依存：T065・T068
- 更新：2026-11-02

## 目的・背景

- 将来、購入で手に入る衣装にしたい。レベルや節目では開かない。別格の動き（スーパーレジェンドのように）で差をつける（ユーザー）
- 課金の仕組みはまだ作らない。同じ水準で作れるよう、手順を文章にまとめる

## 議論（2026-11-01）

- 手順書：`docs/ritsu-special-costumes.md`。骨子：`pipeline/ritsu_special.json`（6案）
- 1着目は「星詠みの裁定者」（ユーザー）
- 動画モデル（Veo）を1本試した：`pipeline/ritsu_video.py`。顔と衣装は崩れなかった。正方形の絵から縦長を作ると上下が黒くなる
- 春告げの巫女は、見本が安全フィルターで断られたので作らない
- 決めたこと（ユーザー合意）：見本は look-2・reveal-2。1着目は一式（絵・動画・声）まで作る。巫女の代わりは作らない。特別な衣装の絵・声・動画は R2 に置いて管理者にだけ渡す（買った人に広げられる形）。ふつうの衣装は今までの置き場所のまま

## 実装

- 配信：`app/worker/special.ts`。`/api/me` が署名つきの通行証（HttpOnly の Cookie）を出す。img・video・audio は Authorization を付けられないので Cookie にした（URL のトークンより、共有で漏れない）
- 演出：`app/src/ritsu/special.tsx`（全画面の動画・小さな決めポーズ・落ちる星）。画面の飾りは html の data-costume
- 動画は 9:16 の絵から作る（正方形から作ると上下が黒くなった）。音は外す
- 見つけて直した不具合：白いドレスが切り抜きで透けた（`char_cut.py` の fill_holes）。金の天秤が色抜きで消えた（`ritsu_special_finish.py` の key_out）

## 確かめたこと（2026-11-01）

- テスト3種（CI も成功）。本番で通行証なしの `/special/` は 403。R2 の中身は手元と一致（1ファイルの sha で確認）
- スマホ幅で本物の絵と動画を流して画面を確認（配信は手元で差し替え。**本物の Cookie での配信と実機の動画再生は未確認**）

## ユーザーに見てほしいこと

- 登場の動画の後半で光が強く、顔が白くなる
- 小さな決めポーズの最後で体をひねり、天秤が隠れる
- お披露目で、セリフの吹き出しが下のタブに少し隠れる（幅の狭い画面。ふつうの衣装のお披露目も同じ）
- 「決め」の動画と専用セリフが、セリフの長さと合っているか

## ユーザーの確認と直したこと（2026-11-02）

- 足がひん曲がっている：腰かけて足を振るコマが十数枚壊れていた（足が真横に伸びて縁に乗る・足首が折れる・縁の線が残る）。指示が「前へ振り上げる」と強すぎたので、下にぶら下げたまま小さく振る指示に変えて作り直した（`pipeline/ritsu_fix_swing.py`）
- 管理者の印を押すと一般の人の見え方に切り替わる（`app/src/AdminBadge.tsx`。読み込み直す。一般の見え方の間は、お披露目を見た印も数えない）
- 衣装の一覧を「いつもの衣装」「特別な衣装」に分けた。未開放に鍵の印。特別な衣装は絵を渡せないので、鍵の印と名前と粒の記号だけ（**一般の人にも「準備中」として見えるようになった**）
- アプリ全体の色は衣装と別に選ぶ（`html[data-world]`）。明るいものもある
- 横切る演出を消した。登場の動画は動きを抑えた
- 残りの4着（袴・歌姫・司書・雪花）を作り、固有の仕組み（`app/src/ritsu/kits.ts`）を5着に入れた
- 歌姫は肩が出る・透ける絵が出たので、首まで覆って透けない服に直して見本から作り直した
