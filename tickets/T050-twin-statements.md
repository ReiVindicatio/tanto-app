# T050 双子の肢（1語違いで○×が逆になる肢を並べて見せる）

- 状態：完了
- マイルストーン：M2 拡充
- 優先度：中
- 依存：
- 更新：2026-10-23（設計レビュー OK：2026-10-23）

## 目的・背景

- 短答は「どこを変えると×になるか」を見抜く試験。過去問には、ほぼ同じ文なのに○×が逆の肢がある
  - 例：shiho-2013-keiho-q01 肢4「刑法各則に規定された行為の**主体**には，法人は含まれない。」（○）と肢5「…**客体**には…」（×）
  - 例：shiho-2023-minpo-q14 イ・ウ（共同抵当で、どちらの土地を実行したかと、誰が代位するかが入れ替わると○×が逆）
- 2026-10-23 に数えた：同じ科目で、前提文の要らない肢どうし、文の似ている度合い（difflib の ratio）0.85 以上で○×が逆の組が 121組（民法75・民訴22・刑法7・商法6・刑訴5・行政法5・憲法1。名寄せで同じ文になった肢の重複を含む）
- 他社の肢別本にもない、このアプリのデータだから作れるもの。素材は法務省の問題と公式の○×だけで、AI の判断を入れずに作れる

## 議論（2026-10-23 決定）

- 範囲：1語違いだけでなく、似た論点の比べっこまで広げる（似ている度合い 0.75〜0.8 当たり。最後の線は Claude が組を目で見て決める）
  - 0.85 以上は80組・約150枚（全体の1.5%）で、普段の学習で出会うのは60枚に1枚ほど。おまけ止まりになるので広げる
  - 名寄せ後の数（2026-10-23）：0.85 以上 80組、0.80 以上 170組、0.75 以上 280組・約480枚。うち同じ問の中の組は 0.85 以上で 47組
- 見せ方：答え合わせの後に「よく似た肢」を出す＋科目の画面に双子だけを続けて解くモード
- 民法の2020年より前の肢が入る組：既定の絞り込み（決定006）に合わせて既定では除く

## 設計

### データ（pipeline）

- `pipeline/twins.py`（新規）：科目ごとに、肢カード（名寄せの代表。○×のあるもの・前提文の要らないもの・review_flag のないもの）の組で、○×が逆で、文の似ている度合い（difflib の ratio、autojunk なし）が閾値以上のものを選ぶ
  - 違う部分（文字の範囲）も組ごとに出す。間の一致が2文字以下なら1つの範囲にまとめる（色がまだらにならないように）
  - 素材は法務省の問題文と公式の○×だけ。AI の判断は入れない
- `export.py` が `app/public/data/twins.json` を書き出す（新しいファイル。問題データの形は変えない）：

```json
{
  "pairs": [{ "a": "shiho-2013-keiho-q01-4", "b": "shiho-2013-keiho-q01-5", "sim": 0.96, "ad": [[12, 14]], "bd": [[12, 14]] }],
  "cards": { "shiho-2013-keiho-q01-4": { "subject": "keiho", "text": "刑法各則に…", "truth": true, "src": "司法 H25 第1問 肢4" } }
}
```

  - 答え合わせの後に、別の年度の束を読まずに相手の肢を出せるよう、肢の本文と○×と出典を持たせる（約480枚で、圧縮して数十KB の見込み）
  - 書き出しの検査：組の両方が○×のある肢カードで、○×が逆であること

### アプリ

- `src/twins.ts`：`twins.json` を、肢カードを最初に開いたときだけ読む（分野の topics.json と同じ）
- **答え合わせの後**（StatementDrill）：解説の下に「よく似た肢（○×が逆）」として、相手の肢の本文・○×・出典を出し、両方の文の違う部分に色を付ける（似ている順に2つまで）
  - 相手の肢が、このあとの出題に入っているときは出さない（答えが先に分かってしまうため）。相手を答えたときに、こちらを出す
  - 民法の2020年より前の肢は、今の肢も2020年より前のときだけ出す
- **双子のモード**（科目の画面の「分野ごと」の下）：「よく似た肢（○×が逆）を続けて解く（N組）」。組の順はシャッフルし、組の2枚は続けて出す（どちらが先かもシャッフル）。1枚目の後は上のルールで相手を出さず、2枚目の後に1枚目と違いを並べて見せる
  - 対象の年度は、科目の画面の絞り込み（民法の改正前を含めるか）に従う。両方の肢がその年度に入っている組だけ
  - 回答は普段どおり記録する（復習の期限にも入る）
- 見出しの文言は「よく似た肢」。「双子」はチケットの呼び名にとどめる（意味が伝わりにくいため）

### テスト

- パイプライン：組の選び方（○×が同じ組・名寄せで同じ肢・前提文つきを除く）と、違う部分の範囲
- 単体：相手を出すかの判定（このあとの出題に入っているか・民法の改正前）
- E2E：答え合わせの後に、よく似た肢が色付きで出る／双子のモードで組の2枚が続けて出て、2枚目の後にだけ相手が出る

## 完了条件

- 答え合わせのあとに双子の肢が、違う部分を目立たせて出る
- 科目の画面から、双子だけを続けて解ける

## 実装の記録

- 閾値は 0.75（`pipeline/twins.py` の THRESHOLD）。0.75〜0.80 の組を目で見て、「文書提出命令／検証物提示命令」「留置権／一般の先取特権」のような比べて覚える組が多かったため
- 組：301組・511枚（2026-10-23）。科目ごとに民法151・民訴72・商法39・刑訴18・刑法11・行政法7・憲法3と偏る。`twins.json` は 194KB（圧縮して約39KB）
- 総当たり（約40秒）は書き出しのたびには遅いので、bigram の重なり（Dice 0.5 以上）で候補を絞る（約4秒）。総当たりと比べて 286組中 280組が残った（落ちたのは閾値ぎりぎりの組）
- 比べるときは全角半角・読点（，、）・「附／付」をならす（文字数は変えない）。違う部分は、漢字・カタカナ・英数字の続きの途中で切れたらその続きの端まで広げる（「主／客」→「主体／客体」）
- 出典の肢の一覧（ids）を持たせ、名寄せした肢は絞り込みに入っている年度の出典で出す
- 画面：答え合わせの解説の下に「よく似た肢（○×が逆）」（`src/TwinsView.tsx`）。科目の画面の分野ごとの下に「よく似た肢（○×が逆）」の欄と「続けて解く（N組）」（`src/screens/TwinSection.tsx`）。1枚が複数の組に出るときは似ている順に先の組だけ使う（数が毎回同じになるように）
- テスト：パイプライン `pipeline/tests/test_twins.py`、単体 `src/twins.test.ts`、E2E `e2e/twins.spec.ts`
- 表示の速さ（2026-10-24、CPU を4分の1に落として測定）：答えてから結果・次の肢までは twins.json のあり・なしで差なし（約40ms）。ただ、その日最初に肢カードを開くときだけ、twins.json（194KB）の解析が最初の1枚の表示とぶつかって約50ms 遅れることがあった → 画面を描き終えて手が空いてから読む（`loadTwinsWhenIdle`。requestIdleCallback、使えなければ 0.3秒後）ようにして、差がなくなった（約59ms で同じ）
