# T004 現行法での正誤と改正情報

- 状態：議論済み（M2 で、解説の量産と合わせて進める）
- マイルストーン：M2 拡充
- 優先度：中
- 依存：T012（解説の量産）と時期を合わせる
- 更新：2026-10-22

## 目的・背景

- 肢の○×は出題時点の公式の正解（`truth_at_exam`）だけ。現行法での正誤（`truth_current`）は全肢 `unreviewed`
- 今は年度単位の注意書き（「出題時点の正解。改正で変わっている可能性」）と、民法の全年度モードで2020年より前を既定で除くことで逃げている（📖 decisions/006）
- 設計 §3.4：改正情報と肢の条文を突き合わせ、影響しうる肢に印を付け、**人が確認する**（AI に現行法の正誤を判定させない：設計 §0-5）

## 議論

### 確かめた事実（2026-10-19）

- **e-Gov 法令 API v2 で、改正の履歴と、指定した日の条文が取れる**（例：民法は 2016-10-13 以降の37の版。`/api/2/law_revisions/<法令ID>`・`/api/2/law_data/<法令ID>?asof=YYYY-MM-DD`）。それより古い版は出てこないので、**H23〜H27（2011〜2015）の出題日の条文は取れない見込み**
- したがって、「出題日の条文」と「今の条文」を比べて、**出題後に本文が変わった条**を年度ごとに機械的に洗い出せる（H28 以降）
- 一方、**肢がどの条文の話かという情報（条文タグ）は、解説のある肢（民法 R08・R06 の150肢）にしかない**。他の約3,000肢には付いていない
- 既にある仕組みも確認の役を担っている：解説は現行の条文で書くので、出題後の改正で結論が変わる肢は、解説の検査（公式の○×との一致）で止まる

### 選択肢

| 案 | 内容 | 良い点 | 気になる点 |
|---|---|---|---|
| A | 年度ごとに「出題後に本文が変わった条」の一覧を作り、解説のある肢は引用条文と突き合わせて、肢ごとに「出題後に改正された条文に関わる（要確認）」を表示する | 機械的で、AI の判断を使わない | 今効くのは解説のある150肢だけ（R08 はほぼ改正なし）。H27 以前は比べられない |
| **B（勧め）** | 今の年度単位の注意書きのまま、T004 は M2（解説の量産と一緒）に移す。A の「変わった条の一覧」は、解説を作る年度に合わせて作り、解説の生成時に改正の有無を確かめる材料にする | 基盤を待たせない。条文タグが増える（解説が増える）ほど A が効くので、作る時期を合わせるのが効率的 | 肢ごとの改正の印は、解説ができるまで出ない |
| C | AI で全肢に条文タグを付け、A を全肢に広げる | 解説を待たずに全肢に印が付く | タグは AI の分類で誤りうる（ただし影響は注意書きの精度だけ。○×は変えない）。約3,000肢分の手間 |

### 決まったこと（2026-10-19）

- **案B**：今の年度単位の注意書きのまま、T004 は M2 に移す。「出題後に本文が変わった条」の一覧（e-Gov v2 の過去の版との比較）は、解説を作る年度に合わせて作り、解説の生成時に改正の有無を確かめる材料にする

### 決まったこと（2026-10-22）

- 解説の生成（T039）が全問ほぼ終わった時点で、**公式の○×と食い違って止めた肢（20肢。現行の条文・判例では公式の○×を説明できない）が、解説だけ外れて肢カードには出題時点の○×のまま出ていた**。覚えると現行法と逆になる
- **案1（実施）**：この20肢を flags.json の `law_changed` にして肢カードから外した（問で解くには残し、「出題後の法改正（判例の変更を含む）で正誤が変わる肢」と注記）。`truth_at_exam` は変えない
  - 名寄せで同じ文・同じ○×の肢（司法と予備の重複）にもフラグを引き継ぐようにした（`export.py` の `dedup`）。引き継ぐと警告を出すので、flags.json にも足す。今回は4肢（shiho-2012-gyosei-q39-c・shiho-2012-minso-q62-4・shiho-2017-keiho-q20-5・shiho-2021-keiho-q12-a）
- **見送り（ユーザー判断「1だけでいい」）**：
  - 案2：外した肢に `truth_current`（現行法での○×、AI の判断と表示）を入れて肢カードに戻す。設計 §0-5「AI に現行法の正誤を判定させない」の変更になる
  - 案3：出題後に改正された条文に関わる肢に注意書きを出す（e-Gov v2 の過去の版との比較・解説の notes にある改正の注記 483肢）
