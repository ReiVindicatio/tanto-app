# T046 閲覧状況の計測（Cloudflare Web Analytics）

- 状態：完了
- マイルストーン：M3 公開
- 優先度：中
- 依存：T044・T045
- 更新：2026-10-21

## 目的・背景

公開して検索に載せたので、どれだけ見られているか（訪問者数・よく見られたページ・どこから来たか）を知りたい。

## 議論（2026-10-21 ユーザー合意）

- Google Search Console（設定済み）：検索での表示・クリック
- **Cloudflare Web Analytics**：訪問者数・閲覧数・参照元・国・端末。無料、Cookie を使わず個人を追わない（同意のバナーが要らない）→ 入れる
- Google Analytics 4：Cookie を使い、データが Google に渡る。いまの規模では重さに見合わない → 入れない

## 設計

- Cloudflare のダッシュボードで Web Analytics のサイトを登録し（ユーザー）、出たトークンで計測のスクリプト（`static.cloudflareinsights.com/beacon.min.js`）を入れる
  - アプリ（`app/index.html`）と問ごとのページ（`scripts/pages.mjs`）の両方
- プライバシーポリシー：「ログインしない場合は何も送らない」を直し、閲覧状況を Cloudflare Web Analytics で計測すること（Cookie 不使用・個人を特定しない・学習の記録は送らない）を書く。預け先に Cloudflare Web Analytics を足す
- 規約の変更はアプリの中で知らせる（ポリシーの5.）→ ポリシーに改定日を書く

## 完了条件

- 公開先のアプリと問のページでスクリプトが読み込まれ、ダッシュボードに閲覧が出る
- 3つのテストが通る

## 結果

- ✅ 計測のスクリプトを、アプリ（`index.html`）と問ごとのページ（`scripts/pages.mjs`）に入れた。公開先のホスト名のときだけ読み込む（手元の開発・E2E の閲覧を数えない）。トークンは秘密ではない（ページに出るもの）
- ✅ プライバシーポリシーを改定（閲覧状況の集計・目的・預け先・改定日）。フッターに改定のお知らせを 2026-11-21 まで出す
