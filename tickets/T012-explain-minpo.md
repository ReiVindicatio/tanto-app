### 作ったもの

- `pipeline/revisions.py`（T004 の決定どおり）：e-Gov 法令 API v2 で出題時点（asof）の版を取り、保存済みの現行の条文と条ごとに比べて、本文が変わった条の一覧を `data/statutes/changes/` に書く。本文の文字列の比較だけで、AI の判断は使わない。出題日は「その年の7月1日」で代用（予備の短答は7月）

### 判例の確認で気をつけたこと

- 判例は検索で確認できたものだけ `cases` に入れた（確認に使った URL は二次資料を含む：決定005）
- 確認できず「判例あり（要確認）」とした肢：R05 問7ウ（譲渡担保の設定者の不法占有者への明渡請求、最判昭和57年9月28日とされる）は、検索で判示の結論部分を確認できなかったので、解釈で説明し、本文に「判例あり（要確認）」と書いた。R04 問4ア（共有の不法占有による損害賠償、最判昭和41年3月3日とされる）も同じ扱い。そのほか、判例の存在は知られているが検索で確かめていない解釈の説明には「（判例あり（要確認））」を付けた
