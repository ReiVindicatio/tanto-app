## 目的・背景

- ユーザーの感想（2026-10-19）：「トップ画面がわかりにくい。全部の法律が同じ色だからかな」「ハンバーガーメニューで分割したほうがいいのかな？」
- 今はホーム1枚に全部が縦に並んでいる

## 議論（論点の候補）

- スマホ向けには、画面下のタブ（ホーム／復習／科目／マイページ）が押しやすい。ハンバーガーメニューは中身が隠れて使われにくい（勧め：下のタブ）
- 科目ごとに色やアイコンを分け、カードの形にする
- 科目の画面（年度ごと・全年度・問で解く）とホーム（今日の○問・続きから）を分ける

## 決まったこと（2026-10-19）

- スマホを主に考え、**画面下のタブ3つ**（ホーム・科目・マイページ）にする。ハンバーガーメニューは使わない（入口が隠れ、毎回2タップになるため。機能が増えてもタブの中の画面に収める）
- 画面ごとに URL を持たせ、スマホの戻る操作（iPhone のスワイプ・Android の戻る）でアプリ内を戻れるようにする
- カラーテーマはユーザーの指定（ea-arena-portal の globals.css）に合わせる。ダークモードも入れる（端末の設定に合わせる／ライト／ダーク）
- 📖 decisions/015

## 設計

### 画面と URL

| URL | 画面 | 中身 |
|---|---|---|
| `/` | ホーム | 今日の成績（今日の回答数・正答率）、今日の復習（科目ごと：期限・新規の残り・はじめる）、科目へのリンク。T022 で「今日の30問」に置き換える |
| `/subjects` | 科目 | 科目ごとのカード（科目の色・年度数・肢カード数・回答済みの割合の棒）。タップで科目の画面へ |
| `/subjects/<科目>` | 科目の画面 | 今日の復習（この科目）、全年度から（民法は改正前を含める切り替え）、肢カードの絞り込み（すべて／未回答だけ／前回まちがえたものだけ）、**年度の一覧**（折りたたまずに並べる。年度ごとに進み具合の棒・肢で解く・問で解く） |
| `/me` | マイページ | アカウント（Google でログイン・同期の状態・ログアウト）、表示（テーマ）、累計の記録（T024 で広げる）、このアプリについて（出典） |
| `/play` | 解いている画面 | 肢カード・問で解く。**タブを隠す**。○×・次へ・採点するのボタンは画面下に固定（親指が届く位置）。再読み込みで中身がなくなったときはホームに戻す |

- 小さな自前のルーター（History API）にする（依存を増やさない）。公開先（Cloudflare Workers）は未知のパスで index.html を返す設定（SPA）が既にある
- ヘッダーはアプリ名と、ログイン中なら同期の状態だけ。ログイン・ログアウトはマイページへ移す
- 出典の表記は全画面の下に残す（CLAUDE.md の「画面に入れる」）

### 見た目

- 色は CSS 変数で持つ：ブランド #f66e61（主要なボタン・選択中のタブ）、文字 #5e696c／#8a9699、背景 #ffffff／#f8f9fa、線 #c4cacc／#d4d9db、chrome #f0f0f0。ダークは指定ファイルの dark の値
- 正誤の色はブランド色と分ける：正解 緑、不正解 濃い赤
- 科目ごとの色（民法・商法・民訴・刑法・刑訴）をカードの左の帯と点に使う
- フォントは日本語のため端末の標準（ヒラギノ・Noto Sans JP）のまま
- テーマの設定は端末に保存する（`tanto.theme.v1`。既定の「端末に合わせる」のときは保存しない）

### その他

- 今日の成績のため、学習の状態に日ごとの回答数・正解数を足す（回答ログから作る。保存するデータは増えない）

### テスト

- 単体：URL と画面の対応、日ごとの集計
- E2E：既存のテストを新しい画面の行き来に合わせて直す。タブで3画面を行き来できる・戻る操作で前の画面に戻る・再読み込みしても同じ画面・ダークモードに切り替わる、を足す

## 実装（2026-10-19）

| ファイル | 内容 |
|---|---|
| `app/src/router.ts` | URL と画面の対応・`navigate`・`back`（履歴に通し番号を持ち、直接開いたときは代わりの画面へ） |
| `app/src/App.tsx` | 画面の切り替えだけを持つ形に書き直し。ヘッダー・下のタブ・出典 |
| `app/src/screens/` | ホーム・科目の一覧・科目の画面・マイページ |
| `app/src/TabBar.tsx` | 画面下のタブ（ホーム・科目・マイページ）。解いている画面では隠す |
| `app/src/play.ts`・`data.ts` | 解く中身の受け渡し（メモリ）・データの読み込み（App.tsx から切り出し） |
| `app/src/theme.ts`・`styles.css` | カラーテーマ（ユーザー指定の色）とダークモード（端末に合わせる／ライト／ダーク） |
| `app/src/AuthBar.tsx` | ヘッダーは同期の状態だけ、ログイン・ログアウトはマイページへ |
| `app/src/StatementDrill.tsx`・`QuestionDrill.tsx` | ○×・次へ・採点するを画面下に固定、進み具合の棒 |
| `app/src/learning.ts` | 日ごとの回答数・正解数（今日の成績・これまでの記録） |

- 設計からの細部の変更：年度の一覧は、1年度を1行（年度・問数・肢数・解説の有無・回答済み、右に「肢で解く」「問で解く」、下に進み具合の棒）にして縦の長さを詰めた
- ○と×のボタンはブランド色を使わず中立の色にした（答える前に色の印象を与えない）
- ホバーの色はマウスのある端末だけにした（スマホでタップ後に色が残らない）
