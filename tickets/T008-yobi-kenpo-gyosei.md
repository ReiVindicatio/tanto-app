## 目的・背景

- 憲法行政法の科目群。H25・H26 はテキスト層が壊れている（T010）
- 行政法は条文が多数の法律に分かれている（行政手続法・行政事件訴訟法・国家賠償法・行政不服審査法・地方自治法など）。解説を作るときは egov.py の LAWS に足す
- 憲法の資料文など、第三者の著作物を含む部分の扱い（設計 §6-1）

- 問題と公式の○×の取り込み（H25・H26 を除く）

### パーサ・検証の直し

| 型 | 例 | 直し方 |
|---|---|---|
| 本文（対話・文章）の中に肢が埋め込まれている「（ア）【…】」 | 行政法に多い（R08 問16 など） | リード文の後ろの本文を前提文（本文）に分け、【 】の中を肢として取り出す。肢の文字は本文と重なるので、検証の照合では数えない |
| 下線部が肢の問（下線の範囲はテキストに残らない） | H23 行政法 問16 | 肢を推測で切り出さず、問で解くだけにする |
| **肢ごとの○×の組合せから選ぶ問**「正しいものに○，誤っているものに×を付した場合の組合せ」 | 憲法・行政法で139問 | **組合せとして導出すると○×を取り違える**ので、今は問題カードにした（下の「決めてほしいこと」）。「〇」（漢数字のゼロ）・「組み合わせ」の表記ゆれも検出する。取り違えは導出の矛盾検査が止めていた |
| 各事例について「それぞれ後記１から３までの中から選びなさい」・【甲群】の各訴訟が【乙群】の１〜５のいずれに当たるか | H30・R04 行政法 問22、H27 行政法 問21 | 区分を選ぶ形式（T033）として扱い、区分は選択肢・乙群の一覧から取る |
| 選択肢が肢のラベルでなく別の一覧（【乙群】のＡ〜Ｆ）の組合せ | H23 行政法 問23・24 | 問題カード |
| 参照条文が選択肢の前・肢の間・本文の前にある | 行政法の各所 | 参照条文の位置を元の行で照合。肢の間の参照条文の後ろで次の肢に戻る。対話の話者の行で参照条文を閉じる |
| 「１. ア○」（半角）の選択肢・字下げされた「１．ア ２．イ」の選択肢 | H23 行政法 問17、H28 行政法 問17 | 読む |
| 見出し「〔第５問 〕 (配 点 ：２)」の空白 | H28 憲法 | 読む |
| 区分のラベルに前の文がくっつく | 憲法の見解の問 | 句点でも区切る |

### 著作権（設計 §6-1）

- 問題文は法務省の公開資料（公共データ利用規約）。判決の引用は著作権の対象外（著作権法13条）。第三者の文章（学説の引用など）が含まれていないかは、**公開（M3）の前に確認する**（自分専用の今は取り込む）
