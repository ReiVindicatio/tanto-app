# T005 同一肢の名寄せ（肢 ID の確定）

- 状態：起票
- マイルストーン：M1 基盤
- 優先度：高
- 依存：
- 更新：2026-10-18

## 目的・背景

- 決定001の3：予備と司法で同じ問題が出ている場合、同一肢を1つにまとめ、出典を複数持たせる。年度をまたいで同じ記述が出ることもある
- **肢 ID が変わる可能性があるので、ログイン・同期（T003）の前に決める**。今は端末内の履歴・FSRS が肢 ID（`yobi-2026-minpo-q01-a`）をキーにしている

## 議論（論点の候補）

- 名寄せの単位：本文の正規化（空白・記号・人物記号の違い）＋完全一致か、類似度か
- ID の形：出典ごとの ID はそのまま残し、名寄せした「カード ID」を別に持つか（勧め：出典 ID は不変、カード ID を追加）
- 同じ記述でも年度で○×が逆の場合（法改正）の扱い → T004 と関係
- 既に端末にある履歴の付け替え（今ならユーザー1人分なので、T020 のエクスポートを使って移せばよい）
