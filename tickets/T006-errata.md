## 目的・背景

- 法務省（司法試験委員会）は、試験後に問題の誤記や採点上の取扱い（全員を正答とする・複数正解など）を公表することがある。今は正本の `status`（voided・all_correct・errata）が空のまま
- `truth_at_exam` を変えてよい唯一の場面（CLAUDE.md 禁止事項2）なので、取りこぼすと「公式には全員正解扱いの問を、特定の○×で覚えさせる」ことになる

## 議論

### 分かったこと（2026-10-19）

手元の資料（`data/raw/予備試験/資料/`）と、法務省サイトの検索で見つかったもの：

| 年度 | 科目・問 | 内容 | 取扱い | 出典 |
|---|---|---|---|---|
| R02 | 一般教養 第11問 | 選択肢の誤字 | 措置なし（解答に影響なし） | 手元の PDF |
| R07 | 一般教養 第41・42問 | 本文の誤記（were→wire） | 措置なし | 手元の PDF |
| H28 | 一般教養 第31問 | 出題の誤り | 選択者を全員正答として扱う | 考査委員会議 議事要旨（検索） |
| H30 | 一般教養 第28問 | 問題文の誤りで正答がなくなった | 選択者を全員正答として扱う | 法務省の公表（検索） |

- **見つかったものは、すべて一般教養（取り込みの対象外）**。法律科目（民法・商法・民訴・刑法）の訂正は、今回の検索では見つかっていない
- 公表の場所は、年度ごとの「短答式試験の結果」のページ・考査委員会議や及落判定会議の議事要旨。検索では網羅できていない

### 選択肢

| 案 | 内容 | 良い点 | 気になる点 |

| **A（勧め）** | 予備 H23〜R08 の各年度について、法務省の「短答式試験の結果」のページと議事要旨を順に確かめ、**年度ごとに「確認済み・該当なし／あり（内容）」を記録**する。法律科目に該当があれば正本の `status`・`official_answer` に取り込む | 「なかった」と言える。以後の年度も同じ手順で足せる | 年度ごとにページを開く手間（Claude が Web から確かめる。法務省の公開資料なので素材の制限にかからない） |

### A にした場合の中身（設計の候補）

- 記録の置き場：`data/review/errata.json`（年度ごとに、確かめたページの URL・確認日・結果）
- 該当があった場合：正本に `status.errata`（内容と出典）、全員正答なら `status.all_correct: true`、複数正解なら `official_answer` を配列に。その問の肢は、肢カードでどう扱うかを決める（全員正答の問は肢カードから外す、が勧め）
- `validate.py`：取り込み済みの年度が `errata.json` で「確認済み」になっていなければ止める（取りこぼし防止）
- 司法試験（T011）も同じ仕組みに載せる

## 実装（2026-10-19）

### 確認の結果

- **予備 H23〜R08（16年度）すべてで、法律科目の誤記・正誤訂正・採点上の取扱いはなかった**。見つかったのは一般教養の4件だけ（上の表のとおり）
- 年度ごとに、年度の結果ページ・短答式試験結果のページ・正解 PDF（4科目分）・短答式試験及落判定会議の議事要旨を確認した（サブエージェントが法務省のページを開いて調べ、確かめた URL を記録）
- Claude が主要な資料を取り直して突き合わせた：H28・R02 の告知 PDF の文言、**2020年の議事要旨には誤記の記載がない**こと（措置なしの誤記は議事要旨に出ないことがある → 結果ページの告知も見る必要がある）、R06 民商民訴の正解 PDF の sha256 が手元の原本と一致すること（法務省側の差し替えなし）
- 参考（予備には影響なし）：**司法試験 R05 の短答 刑法第6問は全員正答の扱い**（性犯罪規定の改正の施行と出題の関係）。予備 R05 の刑法には性犯罪の問題がなく、予備の正解 PDF・議事要旨にも取扱いはない。T011 で司法試験を取り込むときに反映する

### 作ったもの

| ファイル | 内容 |
|---|---|
| `data/review/errata.json` | 年度ごとの確認記録（確認日・確かめたページ・見つかった訂正。訂正の種類は all_correct／voided／multiple_answers／none） |
| `pipeline/common.py` | `errata_record`・`errata_for_question` |
| `pipeline/validate.py` | 取り込み済みの年度が「確認済み」でなければ止める |
| `pipeline/derive.py` | 取り込み対象の科目に全員正答・没問があれば、正本の `status` に記録し、肢の○×を出さない（問題カードにする）。複数正解は止めて相談する |
| `app/src/grade.ts`・`QuestionDrill.tsx` | 全員正答・没問の問は満点で採点し、その旨を表示する |
| `pipeline/tests/test_errata.py` | 全員正答が正本に反映されること・複数正解で止まること（CI でも流す） |

### テスト

- パイプラインの単体2件・回帰（差分なし）・アプリの単体20件（1件追加）・E2E 8件がすべて通る
- 確認記録を1年度消すと検証が止まることを確かめた
- 正本・アプリのデータは変化なし（取り込み対象の科目に該当がないため）。検証レポートに確認の項目が1つ増えた
