# T033 区分を選ぶ形式（classify_each）と刑法の改正の注意書き

- 状態：完了（実装レビュー OK：2026-10-19）
- マイルストーン：M2 拡充
- 優先度：中
- 依存：T009（完了）
- 更新：2026-10-19

## 目的・背景

- T009 で、「肢ごとに１・２（・３）の区分を選ぶ」形式の9問が読めず、刑法 H24・H25・H29、刑訴 H28・H29・R06 の6セットが検証で止まっている
- 刑法は、2023年の性犯罪規定の改正と2025年の拘禁刑の導入で、R07 以前の肢の多くが現行法の文言と合わない

## 決まったこと（2026-10-19）

1. 新しい形式 `classify_each` を足す（📖 decisions/014）。リード文から区分の一覧（「１＝共同正犯」など）を取り出して正本に持ち、**問で解く**では肢ごとに区分のボタンを出して採点する。**肢カードには出さない**
2. 刑法の R07 以前の出題には、「2025年の拘禁刑の導入・2023年の性犯罪規定の改正より前の出題です」と具体的な注意書きを出す。全年度モードで古い年度は除かない

## 実装（2026-10-19）

| ファイル | 内容 |
|---|---|
| `pipeline/parse_questions.py` | `classify_each` の判定（リード文に「…には１を，…には２を」が2つ以上・選択肢の行なし・「正しい／誤っている」ではない）。区分の一覧 `classes` をリード文の文字列そのままで切り出す。解答欄の範囲を肢ラベルなし・①〜⑤の空欄でも読む |
| 同上 | 肢の中の【観念的競合】のような見出し（リード文が空欄の【 】を使う形）を、前提文でなく肢の文として読む。半角で始まる「[№10］」も肢末尾の解答欄として読む |
| `pipeline/validate.py` | 区分の検査（区分が1からの連番・ラベルが空でない・No の数と肢〔空欄〕の数・肢末尾の No の対応・解答が区分の範囲） |
| `pipeline/derive.py` | 正本の問に `classes` を写す。肢の○×は導出しない（問題カードだけ） |
| `app/src/grade.ts`・`QuestionDrill.tsx`・`types.ts` | 問で解くで、区分の番号のボタンと、問の上に区分の一覧（「1：甲に（ ）内の犯罪の共同正犯が成立する場合」など）。正解の表示にも区分の名前 |
| `app/src/LawNote.tsx` | 刑法の R07（2025）以前の出題に「2025年6月の拘禁刑の導入（懲役・禁錮の廃止）より前の出題です。2023年には性犯罪の規定も改正されています…」 |

### 結果

- **刑法 H24・H25・H29、刑訴 H28・H29・R06 の6セットが検証 ✅**。刑法・刑訴とも H23〜R06・R08 の15年度がそろった（R07 は OCR 待ち）
- 区分の問は9問：刑法 H24 問4（3区分）・問8、H25 問6、H29 問9（3区分）、刑訴 H28 問18・問22（①〜⑤の空欄ごと）・問24、H29 問18、R06 問20
- **既存データの変化**：刑法 H26・H27、刑訴 H25 で、肢の文末に半角の「[№34］」が残っていた肢の文からそれが取れ、解答欄との対応も記録されるようになった（○×の変化なし。差分で確認）
