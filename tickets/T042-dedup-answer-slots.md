# T042 名寄せの漏れ：前提文つきの問で、解答欄の番号の違いでまとまらない

- 状態：完了
- マイルストーン：M2 拡充
- 優先度：高
- 依存：T011（決定018）
- 更新：2026-10-21

## 目的・背景

解説の連続生成（T039）の途中で、司法 刑法 q20 と予備 刑法 q13 が事例も肢も同じなのに名寄せされず、2023〜2025 年の3年続けて解説を二重に書いていたことが分かった。

原因：前提文が要る肢（`requires_context`）は、リード文（`stem`）と前提文も同じときだけまとめる（決定018）。リード文の末尾に「（解答欄は、アからオの順に［No.32］から［No.36］）」が入っており、解答欄の番号は試験ごとに違うため、中身が同じでもまとまらなかった。刑法のほか、行政法・刑訴・商法でも起きていた。

## 議論

- 解答欄の番号は問の中身ではないので、比べる前に「（解答欄は…）」の括弧を除く。決定018の規則（前提文とリード文も同じときだけ）の趣旨は変えない
- 2026-10-21 ユーザー合意（全体の見直しの提案の1番目）

## 設計（設計レビューは、上の提案への合意で代えた）

- `pipeline/export.py`：`dedup_context()` を足し、リード文から `ANSWER_SLOTS`（`（解答欄は…）`）を除いてから前提文と合わせて比べる
- 回答ログは書き換えない。司法側の肢 ID は `index.json` の `aliases` で予備側のカード ID に読み替わる（決定018のしくみのまま）
- テスト：`pipeline/tests/test_dedup.py`（番号だけ違えばまとまる／リード文が違えばまとめない／○×が違えばまとめない）

## 完了条件

- 名寄せの数が増え、○×の食い違う組が新しく出ないこと
- 3つのテストが通ること

## 結果

- 名寄せ：2,288肢 → 2,510肢（+222）。○×が食い違う組は新しく出なかった。解説の共有 1,893
- 解説のキュー：427問・1,784肢 → 389問・1,607肢（約40問の生成が不要に）。すでに二重に書いていた35肢は、代表（予備）の解説が使われる
- テスト：パイプライン 33・単体 78・E2E 26 すべて通過
