# 律の衣装の設計書（T065）

1着ずつ、VTuber の新衣装のお披露目のように「どんなときの、どんな衣装か」まで決めてから作る（2026-10-27 ユーザー）。
実在の人物・既存のキャラクター（VTuber を含む）の衣装に似せない。15歳くらいの子として、露出を控えめに。

## 律の変わらないところ（どの衣装でも同じ）

- 顔・目の形と色（ブラウン）・髪の色（ピンクがかった茶色、ゆるいウェーブ）・背丈
- 性格：のんびりで少し眠そう、条文を読むのが好き、むくれるとジト目
- いつもの服（黄色いベストに白いシャツ・紺のスカート）は「勉強モード」

## 1着ごとに決めること

1. 衣装名
2. どんなときの衣装か（場面・律にとってどんな日か）
3. キーワード3つ（迷ったときの判断の軸）
4. 配色（メイン・サブ・差し色の3〜4色）
5. 衣装の細部（上・下・靴・小物・素材感）
6. 髪型と、その理由
7. 持ち物（ふつうの絵／腰かける絵・寝そべる絵でどうするか）
8. しぐさ・表情のくせ
9. お披露目（一枚絵・お披露目のセリフ・その衣装のときだけのセリフ）
10. 開く条件・季節もの（時期に律が話題にする）

進め方：設計書を決める → 見本を3〜4案 → 選ぶ → 一式（約35枚）・一枚絵・セリフ・声 → お披露目の画面で確かめる

## 並べ方（たたき台）：律の一年

- 日常：オフの日（ニット）・夜ふかし（パジャマ）・図書館の日・部屋着（パーカー）
- 季節：春・梅雨・夏・秋・冬
- 行事：夏祭り（浴衣）・ハロウィン・クリスマス
- 節目：試験の日 など

## 1. ひだまりニット（2026-10-27 確定・実装済み）

- どんなときの衣装か：冬のはじめのお休みの日の午後。日の当たる窓辺で、ココアを飲みながら小さな六法を読んでいる。いつものベストを脱いだ、初めての私服
- キーワード：ぬくぬく・ひだまり・オフの日
- 配色：オートミール（メイン）・ココアブラウン（サブ）・ミルクホワイト・いちごミルクのピンク（差し色）
- 衣装：生成りのケーブル編みの大きめのニット（袖は指先まで）、ココア色のチェックの足首丈のロングスカート、もこもこの白いルームソックス
  - この衣装の印（2026-10-27 追加：1回目の見本がふつうの私服に見えたため）：ニットの胸にマグカップの編み込み模様・袖口にココア色のライン・ポケットに小さなマシュマロのチャーム（A）／襟元にいちごミルク色の細いリボン（B）
- 髪型：いつものツインテールをほどいて、ゆるく下ろす（お休みの日だから）。両側にいちごミルク色の大きめのリボン（B）
- 持ち物：ふつうの絵＝マシュマロが浮かんだココアのマグを両手で包む／腰かける絵＝なし／寝そべる絵＝リボンのしおりをはさんだ六法
- しぐさ：袖で口元を隠して笑う・マグで手を温める・少し眠そう
- お披露目の一枚絵：窓辺のクッションに座り、マグを持ったまま振り返る。窓の外に色づいた木
- お披露目のセリフ：「じゃーん……ど、どうかな」「今日はお休みの日の服なの」「髪もほどいてみた。……変じゃない？」「ココア、いれたよ。一緒に飲も」
- ニットのときだけのセリフ（例）：「ぬくぬく……」「袖、長すぎたかも。手が出てこない」「マシュマロ、溶けちゃった」「お休みの日でも、一問だけ」
- 開く条件：Lv.3（最初の着替え）。冬（12〜2月）はホームで「ニットの季節だね」
