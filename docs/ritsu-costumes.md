# 律の衣装の設計書（T065）

1着ずつ、VTuber の新衣装のお披露目のように「どんなときの、どんな衣装か」まで決めてから作る（2026-10-27 ユーザー）。
実在の人物・既存のキャラクター（VTuber を含む）の衣装に似せない。15歳くらいの子として、露出を控えめに。

## 律の変わらないところ（どの衣装でも同じ）

- 顔・目の形と色（ブラウン）・髪の色（ピンクがかった茶色、ゆるいウェーブ）・背丈
- 性格：のんびりで少し眠そう、条文を読むのが好き、むくれるとジト目
- いつもの服（黄色いベストに白いシャツ・紺のスカート）は「勉強モード」

## 1着ごとに決めること

1. 衣装名
2. どんなときの衣装か（場面・律にとってどんな日か）
3. キーワード3つ（迷ったときの判断の軸）
4. 配色（メイン・サブ・差し色の3〜4色）
5. 衣装の細部（上・下・靴・小物・素材感）
6. 髪型と、その理由
7. 持ち物（ふつうの絵／腰かける絵・寝そべる絵でどうするか）
8. しぐさ・表情のくせ
9. お披露目（一枚絵・お披露目のセリフ・その衣装のときだけのセリフ）
10. 開く条件・季節もの（時期に律が話題にする）

進め方：設計書を決める → 見本を3〜4案 → 選ぶ → 一式（約35枚）・一枚絵・セリフ・声 → お披露目の画面で確かめる

## 2. ほしぞらパジャマ（2026-10-27 確定・実装済み）

- 作るときに分かったこと（2026-10-28 パーカー・図書館）：寝そべる絵・寝転びかけの絵で足が3本に描かれた（足を描き直す指示で、元の足を残して足す）。全身の絵の指示に手足の数の指示（`char_image.py` の LIMBS）を付けた。

- 腰かける絵の大きさ（2026-10-28）：表情ごとに絵の範囲で切っていたので、キラキラや帯の消し残しで範囲が広がった表情だけ小さくなり、表情や仕草が変わるたびに大きさと位置が跳ねた（パーカーで人物の高さが 202〜375px）。
