# 律の特別な衣装の作り方（たたき台）

購入でだけ手に入る衣装を、同じ水準でくり返し作るための手順書。ふつうの衣装の作り方は `docs/ritsu-costumes.md` にあり、ここには差分だけを書く。

**状態**：1着目（星詠みの裁定者）を管理者だけに見せて確かめているところ。課金の仕組みはまだ作らない。

## 目標

一目で「これは別物だ」と分かり、買わなくても「いつか欲しい」と思える衣装にする。絵が豪華なだけでは足りないので、**見た目・動き・画面・声・物語の5つすべて**で、ふつうの衣装と差をつける。

## 3種類の衣装の中での位置

| 種類 | 開き方 | 買える？ | 内容 |
|---|---|---|---|
| 学習の衣装 | レベル | 買えない | 日常・季節の服 |
| 節目の衣装 | 模試の提出などの行動 | 買えない | 模試の朝・試験の日 |
| **特別な衣装** | **購入のみ（ランダムなし）** | **買える** | 非日常の舞台衣装 |

- 学習機能（問題・解説・聞き流し）には課金しない。買った人が有利にもならない
- 無料で開いた衣装を、あとから有料にしない
- 一度買った衣装は、消えない・期限が切れない
- 数を絞る。年に2〜4着を目安にする（「量産」は同じ水準で作れるという意味で、たくさん出すという意味ではない）

## 格を上げる5つの差

### 1. 見た目：現実にない服

ふつうの衣装は「律の日常」、特別な衣装は「舞台の上の律」にする。

- 大きなシルエット（マント・長い裾・袖・大きな髪飾り）を1つ入れ、ちびキャラに縮めても形で分かるようにする
- 主題の印を1つ決めて、衣装・髪飾り・背景・画面の飾りに通す（例：天秤と星）
- 色は2色に金属色を1つ。光る・透ける素材を使う
- 髪型も変える。特別な衣装だけの髪型にする

### 2. 動き：その衣装にしかない演出

ふつうの衣装の動きはすべて持ったうえで、次を足す。これが一番の差になる。

| 場面 | 演出 | 長さ | 流れ方 |
|---|---|---|---|
| 着替え・お披露目 | 全画面の登場 | 5〜8秒 | 押すと飛ばせる |
| 3問続けて正解 | 小さな決めポーズ | 2〜3秒 | 答え合わせの上で。解説を隠さない |
| レベルアップ・今日の目標達成 | 全画面の決めの演出 | 3〜5秒 | 押すと飛ばせる。1日に数回まで |
| 待っている間 | その衣装だけの動作を2〜3種類 | 2〜4秒 | ふつうの衣装の仕草の代わりに |
| 寝そべる | その衣装だけの休み方 | 止め絵＋足のコマ | ふつうの寝そべりの代わりに |

### 3. 画面：着ている間、アプリの飾りも変わる

- 律のまわりの粒子（星・花びらなど）
- 吹き出しの枠、正解のときの光り方、律のページとお披露目の背景
- 肢の文や解説の読みやすさには触れない。文字の色・大きさ・行間は変えない

### 4. 声：演技を変える

- その衣装のときだけのセリフを30本以上（ふつうは10本）
- お披露目のセリフを物語にする（5本の感想ではなく、短い場面として）
- 正解・目標達成・レベルアップ・押したときにも専用のセリフを用意する
- 声の指示を衣装ごとに変える（例：少し芝居がかった、落ち着いた話し方）

### 5. 物語：一枚絵を連作にする

一枚絵を3枚作り、起承転結の短い話にする。

1. 導入：いつもの律が、何かを見つける・決心する
2. 変身：衣装の全身が一番よく見える決めの絵
3. 余韻：終わったあとの、素の律

## 動きの作り方

上から順に、安くて安定している。**別格の場面にだけ下の段を使う。**

| 段階 | 方法 | 向いている場面 | 注意 |
|---|---|---|---|
| A | 一部を描き直したコマの切り替え（今の方法） | まばたき・口パク・足 | 大きな動きはできない |
| B | CSS や Canvas の動き・粒子 | 光・星・花びら・跳ねる | 絵そのものは動かない |
| C | 動画モデル（見本の絵から数秒の動画を作る） | 登場・決めの演出 | 下を参照 |

### 動画モデルについて

Google の Veo は、1枚の絵から数秒の動画を作れる。`pipeline/ritsu_video.py`（モデルは `veo-3.1-fast-generate-001`）。

**試した結果（2026-11-01）**：星詠みの一枚絵から登場の演出を6秒。作成は50秒。最初と最後のコマを見比べて、顔・髪飾り・天秤・衣装の模様は崩れていなかった。マントのなびき・星の渦・寄っていくカメラも指示どおり。1本だけの結果なので、毎回こうなるとは限らない。

- **上下に黒い帯が入る**：正方形の絵から縦長（9:16）を作ると、上下が黒くなった。**最初から 9:16 の絵を作る**（`ritsu_video.py sources`）と黒くならない
- **Veo は正方形（1:1）を作れない**：「どのモデルも呼べなかった」で止まる。9:16 か 16:9 にする
- **光を強くしすぎると顔が白くなる**：星詠みの登場の後半で、金の光に顔と髪の色が負けた。指示で光を控えると防げる見込み
- **全画面の演出**は背景ごと動画にする。透明にしなくてよい
- **小さな決めポーズ**は透明が要る。単色の背景で作って色を抜き、透明つきのアニメーション webp にする（未検証）
- **まだ確かめていないこと**：スマホでの再生、ループのつなぎ目、背景の色抜き、ファイルの大きさ（6秒で約2.6MB）
- **費用**：公式の料金表ではまだ確かめていない。Veo 3 Fast で1秒 0.10〜0.15ドルという記事があるので、6秒で1ドル弱の見込み。Google Cloud の請求で確かめる

## 1着で作るもの

| 種類 | 数 |
|---|---|
| ふつうの衣装の一式（表情・腰かける・寝そべる・動きのコマ・仕草・口パク） | 約60枚 |
| 一枚絵（連作） | 3枚 |
| 専用の背景 | 1〜2枚 |
| 動画（登場・決めの演出・小さな決めポーズ） | 3〜4本、計20秒ほど |
| 専用の動作 | 2〜3種類 |
| 専用のセリフと声 | 40本ほど |
| 画面の飾り（粒子・吹き出しの枠・正解の光り方） | 1組 |

費用の目安は、画像が500円ほど（1枚6円前後）。動画は1本1ドル弱の見込みで、作り直しの回数による。

## 企画の案

骨子は `pipeline/ritsu_special.json`。見本は `python3 pipeline/ritsu_theme.py looks --special` で作る。

| 衣装 | 内容 | 主題の印 | 見本を見て気になったこと |
|---|---|---|---|
| **星詠みの裁定者（1着目）** | 夜空のマントで星の天秤を持つ見習い | 天秤と星 | 天秤が実在の意匠に近づかないよう、星の皿を保つ |
| 合格の袴 | 未来の春の日の律 | 桜と袴 | なし |
| 舞台の歌姫 | 一夜だけの舞台 | 光のリボンと照明 | スカートが短く、脚が出すぎている。丈を長くして作り直す |
| 夜想の司書 | 真夜中だけ開く大図書館の主 | 浮かぶ本と銀の鍵 | なし |
| 雪花の姫君 | 冬の城の、雪の結晶のドレス | 氷の結晶 | 有名な映画の氷の姫に近づかないよう、形と色を確かめる |

**作らない案**：春告げの巫女。見本4案のうち3案が、安全フィルター（`PROHIBITED_CONTENT`）で断られた。律は15歳くらいの設定なので、言い回しを変えて通すことはしない。一式で何十枚も作る途中で断られ続ける見込みもある。骨子は `ritsu_special.json` に残すが、作らない

## 設計書に足す項目

`pipeline/ritsu_costumes.json` の項目に加えて、次を書く。

| 項目 | 内容 |
|---|---|
| `unlock` | `"paid"` |
| `motif` | 主題の印 |
| `story` | 一枚絵3枚の話 |
| `voice_style` | 声の演技の指示 |
| `moves` | 場面ごとの演出（場面・長さ・動画への指示） |
| `screen` | 粒子・吹き出しの枠・正解の光り方 |
| `lines` | 正解・目標達成・レベルアップ・押したときの専用セリフ |

## 作る手順

1. 企画：設計書を書く（主題の印と物語を先に決める）
2. 見本：立ち絵4案と一枚絵を作り、選ぶ
3. 一式：`pipeline/ritsu_theme.py build`（今の手順のまま）
4. 動画：選んだ見本から作り、確かめる
5. 飾り：粒子・枠・光り方を作る
6. セリフと声
7. 通して確かめる：スマホの幅、暗い表示、視差効果を減らす設定、演出を飛ばせること、解説が隠れないこと

### コマンド

```
CHAR_PY=<Pillow のある python>
python3 pipeline/ritsu_theme.py looks <ID> --special              # 見本4案・一枚絵2案。設計に pick を書く
CHAR_PY=$CHAR_PY python3 pipeline/ritsu_theme.py build <ID> --special   # 一式・連作の絵・背景・セリフと声（audio/samples_char/special/<ID>/）
python3 pipeline/ritsu_video.py sources <ID>                      # 全画面用の縦長の絵・小さな決めポーズ用の単色の背景の絵
python3 pipeline/ritsu_video.py <ID> entrance <縦長の絵> --seconds 8 --aspect 9:16
python3 pipeline/ritsu_video.py <ID> finish <縦長の絵> --seconds 6 --aspect 9:16
python3 pipeline/ritsu_video.py <ID> small <単色の背景の絵> --seconds 4 --aspect 9:16
$CHAR_PY pipeline/ritsu_special_finish.py pack <ID>               # 音を外す・途中から再生できる形に・色を抜く
python3 pipeline/ritsu_special_finish.py upload <ID>              # R2 の special/<ID>/ へ
```

`--special` を付けないと公開フォルダに書き出すので、必ず付ける。セリフの文は `app/src/ritsu/lines.json` に入る（公開される）が、声は入らない。

## 守ること

- 律の設定は15歳くらい。露出を増やさず、体の線を強調しない
- 実在の人物・既存のキャラクター・他のゲームの衣装に似せない
- 法務省が関わっているように見せない。実在の法服・弁護士バッジ・裁判所や官庁の紋章は使わない（天秤は架空の意匠にする）
- 律に法律の中身を言わせない（ふつうの衣装と同じ）
- 長い演出は節目だけにする。答え合わせの流れを止めない。全部の演出を飛ばせるようにし、視差効果を減らす設定なら流さない
- ランダムな販売をしない。アプリ内通貨を作らない。根拠のない「今だけ」で急かさない

## 課金を入れるときに必要なこと

- **絵と動画をサーバーから渡す（できている）**：絵・声・動画は R2 の `special/<ID>/` に置き、git にも `app/public/` にも入れない。`/api/me` が署名つきの通行証（Cookie。7日。鍵は秘密の設定 `SPECIAL_KEY`）を出し、`/special/*`（`app/worker/special.ts`）が確かめて渡す。**今は管理者にだけ出す**
- **買ったことの記録はサーバーに持つ（まだ）**：`/api/me` で購入を確かめて通行証を出すようにする。今の通行証は衣装を区別しないので、衣装ごとに売るなら、通行証に買った衣装を入れる
- **試着**：買う前に動きと声を見られるようにする（ここが一番の売り場になる）
- **確かめること**：法務省の資料を有料アプリで使えるか／Gemini で作った絵と声の商用利用（無料トライアルのクレジットで作った分も含む）／特定商取引法の表記／アプリストアの課金と手数料・審査

## 決めていないこと

- 価格
- 売り場（アプリストア・Web）
- 動画モデルの費用
