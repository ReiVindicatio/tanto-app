# 法務省の PDF をリポジトリにコピーして git で管理する（2026-10-18）

> 決定の記録。**以後編集しない。**運用の現行版は `CLAUDE.md`・`docs/design.md`。

## 何が起きたか

設計の初版では「PDF は manifest の URL から法務省に取りに行き、git には入れない」としていた（出所を1本にするため）。ユーザーから「過去問はそっちのリポジトリにコピーしないの？」と聞かれ、量を測った。

## 決めたこと

- `../yobishiken/kakomon/` にある短答の問題・正答の PDF（211件）と資料の PDF（33件）を、`data/raw/` に**同じフォルダ構成で**コピーし、git で管理する（計244件・50MB）
- `sources/manifest.json` に、取得元 URL（問題・正答は全件あり。資料は記録なし）・取得日（2026-09-05）・コピー元・sha256・バイト数を記録する
- `.txt` はコピーしない。テキスト化はこのリポジトリのパイプラインでやり直す（予備 H25・H26 の一部で、yobishiken 側の `.txt` が文字化けのままだったため）
- 法務省から取りに行くのは、抜けている年度（司法 H23〜H26 の正答など）と新しい年度だけ

## 理由

- **量が小さい**：50MB。private リポジトリで困る量ではない
- **法務省が古い PDF を消すリスク**：司法 H23〜H26 の短答の正答が manifest にないのは、ページの構成変更か削除の可能性がある。手元の取得分は、それ自体が残す価値のある原本
- **出所はハッシュで担保できる**：コピーでも、URL・取得日・sha256 があれば出所を追える。取り直したときに sha256 を比べれば、法務省側の差し替えも検出できる

## 採らなかったこと

- **manifest から毎回取り直す**：再現性はあるが、法務省のページが変わると取れなくなる（User-Agent なしの curl には 403 を返すことも確認済み）
