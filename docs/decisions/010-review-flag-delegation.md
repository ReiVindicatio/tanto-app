# 要確認の肢の判断は Claude に任せ、根拠と確度を残す（2026-10-18）

> 決定の記録。**以後編集しない。**運用の現行版は `tickets/README.md`・`data/review/flags.json`。

## 何が起きたか

予備 R06 民法 問5アを要確認（決定008）にし、判断材料をユーザーに示したところ、「出題の慣行だけで決めてよい。Claude のほうが正確に判断できるので裁量で決めてよい」と委任された。

## 決めたこと

- `data/review/flags.json` の要確認の肢は、**Claude が判断して resolved にしてよい**。`resolution` に結果・根拠・確度（高／中／低）・判断者・日付を書く
- 慣行（convention）による○×は、反対の明文・判例が見つからない限り、**出題の慣行に従って公式の扱いどおりにする**。明文の根拠がないことは解説と notes に書く
- `truth_at_exam` は変えない（禁止事項2）。判断の対象は「肢カードに出すかどうか」と「解説の書き方」
- 反対の明文・判例が見つかった場合（公式の扱いと条文が明らかに食い違う場合）は、resolved にせず open のままユーザーに示す

## 適用

- R06 民法 問5ア：○として肢カードに戻した（確度：中）
