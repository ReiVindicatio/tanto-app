# 同一肢の名寄せは保留し、「出典の肢 ID は変えない」だけを守る（2026-10-19）

> 決定の記録。**以後編集しない。**

## 何が起きたか

T005（同一肢の名寄せ）の議論で、予備 民法15年度（1,112肢）の重複を数えたところ、本文が同じ肢は4組・8肢だけだった。ユーザーから「名寄せは必要か。同じ問題が出ることは致命的とは思えない」と指摘があった。

## 決めたこと

- 名寄せは**保留**する（T005 を保留、マイルストーンを M2 に移す）。司法試験の短答を取り込む（T011）ときに、重複の実数を見て要否を決め直す
- 守る約束は1つ：**出典の肢 ID（例：`yobi-2026-minpo-q01-a`）は一度公開したら変えない**。変えざるを得ないときは、旧 ID → 新 ID の対応表を残す
- T003（ログインと同期）の依存から T005 を外す

## 理由

- 名寄せしない場合に起きるのは、同じ肢が2枚のカードになる（復習が二重になる・2枚目は記憶で解けて正答率がやや甘くなる）ことで、誤った知識を覚えさせる害ではない
- 回答ログは出典の肢 ID で記録している（T020）。名寄せは「どの肢が同じカードか」の対応表を読み込み時に当てれば足りるので、後から入れても学習記録を移し替えずに済む。今やらなくても失うものがない
