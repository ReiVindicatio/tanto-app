# 解説は全科目について、夜間も続けて生成する（2026-10-19）

> 決定の記録。**以後編集しない。**手順の現行版は `prompts/explain-runbook.md`・`prompts/explain-v2.md`。決定004（1セッション5問程度）を改める。

## 何が起きたか

予備・司法の取り込みが終わり、肢カードは 9,759枚になったが、解説があるのは約8%（民法 R02〜R08）だけだった。CLAUDE.md には「生成する科目はユーザーの学習が終わった科目から」とあった。

## 決めたこと（ユーザーの指示）

- **「学習を終えた科目から」の制限をやめ、全科目の解説を最後まで生成する**（ユーザー：「どうせ AI の解説って書いてるんで、最後まで生成し切って欲しい」）
- 生成は `/loop` で続けて回す。メインのセッションがキューから9問ずつ取り、**サブエージェント3本で並行して**書く（1本3問）。1問ずつ書き出して検査を通す点は変えない
- **このループでは、バッチごとに commit・push してよい**（ユーザーの許可）。公開版にもそのまま出る
- 検査（公式の○×との整合・条文の照合・判例の確認）に通らない肢は今までどおり公開しない。2回直しても通らない問は `data/review/explain_skips.json` に残してキューから外す
- 民法の改正前の年度（2019年以前）は、扱いを決めるまで（T013）キューに入れない

## 残る危うさ

- 人が見ないので、検査で止まらない誤り（○×は合っているが理由が違う、など）は残りうる。AI が生成した解説である表示と、誤り報告（T015）で補う
