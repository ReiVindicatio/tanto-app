# 導出の根拠が疑わしい肢は data/review/flags.json に記録し、確認が済むまで肢カードから外す（2026-10-18）

> 決定の記録。**以後編集しない。**

## 何が起きたか

民法 R06 問5アの解説を書く際、公式の○×（○、慣行による導出）を支える条文が見つからず、条文上はむしろ×寄りに読めた。選択肢の組み方から、アが誤りでも公式の正解（エオ）は成り立つため、慣行（誤りはちょうど2つ）以外に○の根拠がない。

## 決めたこと（Claude の判断。後でユーザーに確認する）

- `truth_at_exam` は変えない（禁止事項2）。代わりに `data/review/flags.json` に、肢 ID・理由・状態（open／resolved）を記録する
- `export.py` は open の肢に `review_flag` を付け、アプリは**肢カード（全年度・年度ごと・今日の復習）から外す**。問で解く（本番形式）には残し、「要確認」と表示する
- その肢の解説は「結論を出せない」（`stated_truth: null`）として検査で止め、公開しない
- 人が確認したら status を resolved にして結果を書く（○の根拠が見つかれば肢カードに戻す。法務省の公表などで扱いが分かれば、それに従う）

## 理由

- 慣行頼みの○×は、決定003で「食い違ったら最初に疑う」とした。疑わしいまま肢カードに出すと、誤った知識を覚えさせるおそれがある
- 問で解くは公式の解答（組合せ）で採点するので、肢単位の疑いがあっても正しく採点できる
