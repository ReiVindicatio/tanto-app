# 画面構成は画面下のタブ3つと URL、カラーテーマはユーザー指定に合わせる（2026-10-19）

> 決定の記録。**以後編集しない。**

## 何が起きたか

ホーム1枚に全科目の「今日の復習」「全年度から」「年度ごと（折りたたみ）」が縦に並び、スマホ幅で画面3枚分あった。ユーザーから、スマホで使うことが多いので見やすくしたい、ハンバーガーメニューにしてはどうか、という相談があった。

## 決めたこと

- 画面下のタブ3つ（ホーム・科目・マイページ）。ハンバーガーメニューは使わない（ユーザーから判断を委任された）
- 画面ごとに URL を持たせ、スマホの戻る操作で戻れるようにする
- 年度は折りたたまずに科目の画面で一覧にする
- カラーテーマはユーザーの別プロジェクト（ea-arena-portal の globals.css）の色に合わせ、ダークモードも入れる。正誤の色はブランド色（#f66e61）と分ける

## 理由

- 行き先が3〜4個なら、親指が届く下のタブのほうが少ない操作で行ける。ハンバーガーは入口が隠れて使われにくい
- 機能が増えても、タブの中の画面（ホームの今日の30問、マイページの記録など）に収められる
- ブランド色は赤系で、「不正解」の赤と同じ色だと紛らわしい
