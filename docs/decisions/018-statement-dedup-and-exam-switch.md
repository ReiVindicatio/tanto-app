# 同じ肢は1枚のカードにまとめ（名寄せ）、科目の画面で予備・司法を切り替える（2026-10-19）

> 決定の記録。**以後編集しない。**名寄せの規則の現行版は `pipeline/export.py`。決定011（名寄せの保留）を引き継ぐ。

## 何が起きたか

司法試験の短答（H27〜R08 の憲法・民法・刑法）を取り込むにあたり（T011）、予備との重なりを肢の本文で数えたところ、司法の肢 3,874 のうち 1,439（37%）が予備と同じだった。名寄せしないと、同じ肢が2枚のカードになり、今日の○問・復習で二重に出る。

## 決めたこと（Claude の提案にユーザーが OK）

- **名寄せを入れる**。同じ科目で、本文が同じ（全角半角・空白・句読点をならして比べる）で、出題時点の○×も同じ肢を1枚のカードにまとめる。前提文が要る肢（会話・見解など）は、前提文とリード文も同じときだけまとめる
  - ○×が食い違う組はまとめない（書き出し時に一覧に出す）
  - カード ID は、まとめた肢のうち予備の肢（同じ試験なら古い年度）の ID。予備の肢 ID はすでに公開し、回答の記録がある
- **回答ログは出典の肢 ID のまま記録し、読み込み時に「出典の肢 ID → カード ID」の対応表（`index.json` の `aliases`）で読み替える**。ログは書き換えない（決定011の約束どおり）。名寄せの規則を変えても、ログはそのまま使える
- 肢カードに、まとめた他の出典を出す（「同じ肢：司法 R06 第5問ア」）。解説は、まとめた肢のどれかにあれば他の出典の肢にも付ける（○×が同じなので結論も同じ）
- 年度を選んで解くときは、その年度の肢として全部出す。複数の年度・科目から出すとき（全年度・今日の復習・今日の○問・まちがえた肢）は1枚にする
- 予備の中で本文が同じ4組も、同じ規則でまとめる
- **画面**：科目の画面に「予備／司法」の切り替えを置き、年度の一覧と「全年度から」を試験ごとに分ける。今日の復習・今日の○問・科目ごとの進み具合は両方を合わせる（名寄せ後の枚数）

## 理由

- 重なりが37%あり、二重に出る害（復習が二重になる・2枚目は記憶で解ける）が無視できなくなった
- 読み込み時に読み替える形なら、ログを書き換えずに入れられ、後から規則を見直しても失うものがない
