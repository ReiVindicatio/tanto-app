# 027 ベータ版の間にログインした人に、星詠みを渡す（2026-11-07）

## 決めたこと

- アプリはしばらく（1年くらい）ベータ版にする（バグが出るため）。上の帯のアプリ名の横に「β版」を出す
- ベータ版の間に Google でログインした人に、課金衣装の見本「星詠みの裁定者」を渡す。もらった人はずっと着られる（退会すると消える）
- 期間の終わりは今は決めない。ベータを終えるときに `app/src/earlyAccess.ts` の `until` に書く。縮める方向には変えない
- 持っている衣装は D1 の `special_owned` に記録する。将来の販売でも同じ表を使う

## 検討したこと

- `026` で見送った「1着を全員に常に開放する」とは別：期間のあとは手に入らないので、「簡単には手に入らない」方針を保てる
- 期間は X に投稿してから2週間・1か月の案もあった。ベータ版の間ずっとにしたのは、「ベータに付き合ってくれたお礼」として筋が通り、バグに付き合う理由にもなるため（ユーザーが選んだ）
- 期間中に来た人は全員星詠みを持つので、星詠みはほぼ売れなくなる。ベータの間はそもそも売らないので、実害は小さいと判断した
- 配る衣装は6着から選べる案もあったが、星詠みで固定にした（ユーザー。見本として作った衣装で、作る量も少ない）

## 分かっていないこと

ベータを終えたあとに来た人が、星詠みを持っていないことをどう受け止めるか。お試し（T070）は残してあるので、ベータのあとはお試しが入口になる。
