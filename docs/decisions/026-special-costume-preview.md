# 026 課金衣装を買う前に見せる範囲（2026-11-04）

## 決めたこと

- 買う前に一式を試せるのは見本の1着（星詠み）だけ。1人1回、20問か48時間
- 残りの4着は全身の絵1枚・名前・紹介文だけ。動き・技・声・背景・お披露目は買うまで見せない
- 見本は Lv.5 のあと、ホームに戻ったときに勝手に着替わる。ログインが要る
- 買う手段を作るまでは、終わりの画面と一覧に「欲しい」を置き、衣装ごとの数を D1 に残す

## 検討したこと

- 10分の試着：自分で押す人にしか届かない。全画面の技は節目で出るので、10分では見られないことがある。アプリを閉じている間も減る。問の数で数えることにした
- 1着を常に解放：その1着が好きな人は買う理由がなくなる。「無料で開いた衣装をあとから有料にしない」決まりがあるので、やり直せない
- 5着すべてをお試しにする案（Claude の最初の案）：ユーザーが却下。買ったときの驚きを先に使ってしまう
- 4着の絵も見せない案（ユーザーの最初の案）：動きは隠すが、服の絵は見せることで合意。何を買うか分からないとくじに近く、「ランダムな販売をしない」決まりの趣旨に合わないため

## 分かっていないこと

決めた時点で D1 に回答記録があるのは開発者1人だけで、どの見せ方が売れるかはデータがない。見本が刺さらなければ、残りの4着も売れにくい。
