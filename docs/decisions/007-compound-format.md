# 小問（⑴⑵）つきの問を format: "compound" として取り込む（2026-10-18）

> 決定の記録。**以後編集しない。**

## 何が起きたか

予備 H26 民法 問5は、1つの問の中に小問⑴⑵があり、それぞれに3つの選択肢と解答欄（No.5・No.6）がある形式だった。既存の形式のどれにも当てはまらず、検証で止まった。

## 決めたこと（Claude の判断。スキーマの追加なので、後でユーザーに確認する）

- Question に `sub_questions: [{marker, stem, format, polarity}]` を足し（小問のない問は空配列）、`format: "compound"` とする
- 肢と解答欄に `sub`（何番目の小問か、0始まり）を足す。肢 ID は `…-q05-1-2`（小問1の肢2）とする
- 各小問は単一選択として○×を導出する（選ばれた肢は selected、残りは uniqueness）
- アプリでは、肢カードに小問のリード文を一緒に表示する

## 理由

- 15年度の民法で1問だけだが、黙って落とすと「なぜこの問がないのか」が分からなくなる。導出も既存の規則（単一選択）で済む
