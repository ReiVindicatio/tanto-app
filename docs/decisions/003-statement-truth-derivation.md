# 肢の○×の導出規則と、正本スキーマの差分（2026-10-18）

> 決定の記録。**以後編集しない。**運用の現行版は `docs/design.md`・`pipeline/derive.py`。

## 何が起きたか

R08 刑法で段階0〜3を通したあと、段階5（肢の○×の導出）の前に2点が問題になった。Claude が提案し、ユーザーが「おすすめでいい」と合意した。

1. 「正しいものの組合せ」（「全て選んだ」がない形）では、**選ばれなかった肢が×だとは文言上は決まらない**。「正解が1つに決まる」ことから証明できる肢もあるが、証明できない肢が残る（R08 刑法の問6ア・問8エ）
2. 設計（§3.2）の Question の形では、前提文が2つある問（問7：【見解】と【事例】）を表せない

## 決めたこと

### 導出の根拠を `truth_at_exam.basis` に区別して残す

| basis | 意味 | 例 |
|---|---|---|
| `direct` | No ごとに公式解答がある（1＝正しい／2＝誤り） | 各肢○×式 |
| `selected` | 公式解答で選ばれた肢 | 組合せの正解に含まれる肢 |
| `exhaustive` | 「全て選んだ場合の組合せ」なので、選ばれなかった肢は逆 | R08 問1・問10 |
| `uniqueness` | 「正解は1つ」から証明できる（その肢が逆でないと、別の選択肢も正解になる） | 単一選択・2個選択の残りの肢、組合せの一部 |
| `convention` | 文言からも一意性からも決まらず、出題の慣行（正解の組合せ＝polarity 側の肢の全部）による | R08 問6ア・問8エ |

- `convention` の肢も肢カードにする。ただしデータ上は区別し、解説の整合チェックで公式と食い違ったら最初に疑う
- 個数問題・穴埋め・○×の向きがない問（R08 問4「窃盗罪の成立を否定する主張となるもの」）は導出しない（`truth_at_exam: null`、問題カード）

### 正本（`data/questions/`）のスキーマを設計から変える点

- `context` を配列にする（`[{kind, text}]`）
- 追加：`exhaustive`・`unordered`・`choices`（構造化した選択肢）・`answer_slots[].statement_label`（各肢○×式）・`provenance.line_range`（抽出テキストの行番号）

## 採らなかったこと

- **証明できる肢だけを肢カードにする**：R08 刑法だけで2肢、年度を広げると相当数が落ちる。慣行が崩れた例は今のところ知られておらず、落とすより区別して持つほうが得
- **慣行どおり全部を同じ扱いにする**：危うさがデータから消え、後で疑う順番が付けられない
