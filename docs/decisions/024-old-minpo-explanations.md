# 民法の2019年以前の肢も現行の条文で解説を書き、説明できない肢は解説を出さずに印を付ける（2026-10-26）

> 決定の記録。**以後編集しない。**手順の現行版は `prompts/explain-v4.md` の「民法の2019年以前の問」。T013。

## 背景

- 民法の2019年以前（債権法改正〈2020年4月施行〉より前）の問は、`explain_queue.py` の1行で解説の対象から丸ごと外していた（決定021）。聞き流しの対象で解説のない肢 1,766 のうち 1,685 がこれで、家族法・物権など債権法改正と関係のない肢まで解説がなかった
- 民法以外の科目の古い年度は、すでに現行の条文で解説を書き、公式の○×に行き着かなければ止める（禁止事項2）作り方で進めている

## 決めたこと（ユーザーと合意）

- 民法 H23〜R01 の肢も、現行の条文（e-Gov）で解説を書く。公式の○×（出題時点の正解）は変えない
- 現行の条文で公式の○×に行き着かない肢、肢の前提の制度・規定が今の条文にない肢（瑕疵担保責任・短期消滅時効など）は、解説を書かず、解説ファイルの `law_changed` に理由（今の条文のどこが肢の前提とどう違うか。今の条文の本文だけを引用）を書く。**現行法での○×は言わない・作らない**（T004 で AI による現行法の正誤の判定は却下済み）。迷ったら解説を出さない方に倒す
- `law_changed` の肢は検査で `status: law_changed`（公開しない）。`explain_commit.py` が `data/review/flags.json` に `kind: law_changed` で記録し、書き出しで肢カードから外れる。問の画面には「出題後の法改正で、正誤が変わっている可能性があります」（AI の判定なので言い切らない）
- H29〜R01 は出題時点の条文を e-Gov の過去の版（API v2 の asof。2016年10月以降の版だけ）で読める。`revisions.py --with-old-text` で試験の直前（5月1日）の版を保存し、`egov.py 民法 <条> --asof <日付>` で読んで結論が変わるかを確かめる。読むだけで、引用は現行の本文から。H23〜H28 は過去の版がないので、この確かめはしない
- 民法の2019年以前の解説には「現行の条文で説明しています（出題時点の条文とは異なることがあります）」と表示する
- 決定013（食い違ったら出題時点と現行法の両方の結論を書く）と explain-v3（自分の結論を書いて止める）の食い違いは、民法の2019年以前については上の `law_changed` に揃える
