# 判例は「検索で年月日と判示が一致したもの」だけ載せ、確認に使った URL を残す（2026-10-18）

> 決定の記録。**以後編集しない。**運用の現行版は `prompts/explain-vN.md`・`pipeline/check_explanations.py`。

## 何が起きたか

民法 R08 問2〜問15の解説で判例を載せる際、裁判所の判例ページ（courts.go.jp）を探したが、検索では引き当てられず、候補の URL も 404 か別の事件だった。検索で見つかるのは予備校系の判例解説サイトや大学の論文が中心だった。

## 決めたこと（Claude の判断。ユーザーの「任せる」の範囲）

- 判例を載せるのは、**検索で、事件の年月日と判示の内容が確認できたもの**だけ。判例の要旨は自分の言葉で要約し、画面では「このアプリによる要約」と明記する
- 確認に使った URL は解説データの `cases[].verified_urls` に残す。**二次資料（予備校系サイトを含む）でもよいが、素材（文章）には使わない**。画面には出さない（`export.py` が落とす）
- 裁判所名は、小法廷まで確かめられないときは「最高裁判所」にとどめる
- 判例があるかどうか確かめていない論点は「判例あり」と書かず、「〜と解されている」と書いて `notes` に「解釈による」と残す
- 判例が別の事案（例：債務不履行解除）についてのもので、肢の事案（例：期間満了）に当てはめるときは、そうと書く

## 理由

- CLAUDE.md の禁止事項1（他社の解説を素材にしない）と禁止事項4（判例は検索で確認できたものだけ）の両方を満たすには、「確認には使うが、文章には使わない」と分けるのが現実的
- 原典（判例集・裁判所の全文）で照合できていないので、ユーザーが学習で使う前に確認できるよう、確認元を残しておく
