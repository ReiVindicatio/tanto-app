# 「肢ごとの○×の組合せ」から選ぶ問は形式 mark_combination とし、肢の○×を導出する（2026-10-19）

> 決定の記録。**以後編集しない。**導出規則の現行版は `pipeline/derive.py`・`docs/design.md` §3.3。

## 何が起きたか

憲法・行政法の取り込み（T008）で、「次のアからウまでの各記述について，正しいものに○，誤っているものに×を付した場合の組合せを，後記１から８までの中から選びなさい」という問が約140問（両科目の問の約4割）あった。選択肢は「１．ア○ イ○ ウ○」「２．ア○ イ○ ウ×」…と、肢ごとの○×を全部書いたもの。

組合せ（`combination`）として導出すると○×を取り違える（選択肢に出てくるラベルを「選ばれた肢」と読んでしまう）。T008 では矛盾検査がこれを止め、いったん問題カード（`meta_choice`）にした。

## 決めたこと（ユーザーと合意：T035）

- 正本の形式に `mark_combination` を足す。選択肢に `marks`（`[{label, value}]`。○＝true・×＝false）を持つ（スキーマの変更）
- 肢の○×は、公式の解答の選択肢に書かれた各肢の○×そのもの。`basis` は `direct`（No ごとに公式解答がある各肢○×式と同じ確かさ。一意性や慣行の推論は使わない）
- 検証：選択肢の○×の並びが肢のラベルと一致し、重複がないこと。選択肢の文字が「ア○ イ× …」だけでできていること
- 矛盾検査：導いた○×に一致する選択肢が、公式の解答ちょうど1つであること
- 肢がテキストに残らない問（下線部が肢の問）は、これまでどおり問題カード

## 理由

- 公式の解答から肢の○×が文言どおりに決まり、推論が入らない。誤りが入る余地は各肢○×式と同じ
- 肢カードが約400枚増え、憲法・行政法の肢カードが今の2〜3倍になる
