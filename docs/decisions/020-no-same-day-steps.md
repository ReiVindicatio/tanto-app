# 間隔反復で、同じ日のうちの短い間隔の復習を使わない（2026-10-19）

> 決定の記録。**以後編集しない。**

## 何が起きたか

ユーザーから「今日の○問で同じ問題ばかり見る」と指摘があった。調べると、ts-fsrs の既定（Anki と同じ「学習ステップ」）で、初めて正解した肢は10分後、不正解の肢は1分後に期限が来ていた。今日の○問は期限が来た肢を先に選ぶので、少し後にもう一度開くと、直前のセットがそのまま「復習」として戻ってきた。

## 決めたこと（Claude の提案にユーザーが OK）

- ts-fsrs の `enable_short_term` を切る。初めて正解した肢は3日後、不正解の肢は翌日に期限が来る
- 今日の○問の「まちがえた」「おさらい」の枠からも、今日答えた肢を外す（不正解の肢は翌日の復習で出る）
- 同じ日に解き直したいときは、結果画面の「まちがえた肢だけもう一度」・マイページの「まちがえた肢をまとめて解く」を使う
- 状態は回答ログから毎回作り直すので、過去の回答にも新しい間隔が当てはまる（ログは書き換えない）

## 理由

- ○×は2択で、数分後の再出題は記憶で解けてしまい、覚えたかどうかの確かめにならない。量をこなすほうを優先したい（ユーザーの方針）
