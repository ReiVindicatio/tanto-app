# 民法の2019年以前の肢で、名前だけが変わり規律と結論が同じなら、印を付けずに解説を書く（2026-10-26）

> 決定の記録。**以後編集しない。**手順の現行版は `prompts/explain-v5.md` の「民法の2019年以前の問」。T013・決定024 の線引き。

## 背景

- 予備 R01 の民法15問を試しに作ったところ（explain-v4）、問11ウ・オは「瑕疵担保責任」という言葉が今の条文にないことだけを理由に law_changed になった（中身の規律と結論は今の636条・559条＋572条でも同じ）。一方、問7ウ（「貸金等根保証契約」→ 今は「個人貸金等根保証契約」）は解説を書いていて、扱いがそろっていなかった

## 決めたこと（ユーザーが B を選んだ）

- 肢の言葉・制度の名前だけが今の条文になく、肢が問うている規律の中身（要件・効果・例外）と結論が今の条文でも同じなら、law_changed にせず解説を書く。本文に名前が変わったことを書く
- 要件・効果・期間・起算点のどれかが変わっていれば、名前の問題ではなく law_changed。今の条文の本文と肢の文から「中身が同じ」と言い切れないときも law_changed（H23〜H28 は出題時点の本文を読めないので、この判断は今の条文と肢の文の比べだけになる）
