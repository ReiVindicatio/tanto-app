# 「肢ごとに区分を選ぶ」問は新しい形式 classify_each として問で解くだけで出す（2026-10-19）

> 決定の記録。**以後編集しない。**

## 何が起きたか

刑法・刑訴の取り込み（T009）で、「甲に共同正犯が成立する場合には１を，教唆犯又は幇助犯が成立する場合には２を，間接正犯が成立する場合には３を」「直接証拠に該当するものには１を，該当しないものには２を」のように、肢ごとに区分を選ぶ問が9問あり、既存の形式（各肢○×など）では読めなかった。

## 決めたこと（ユーザーと合意）

- 正本の形式に `classify_each` を足す（スキーマの変更）。リード文から区分の一覧を取り出して持つ
- **問で解く**では肢ごとに区分のボタンを出して採点する
- **肢カードには出さない**。2区分でも「○＝成立する」のように読み替えると、AI・人の判断で問題の意味を変えることになるため（禁止事項2の趣旨）
- 実装は T033

## 理由

- 6セットが検証で止まっており、問で解くだけでも使えるようにする価値がある
- 肢カードに出すかどうかは、使ってみてから改めて考えればよい（問で解くの採点は公式の解答そのもので、誤りが入らない）
