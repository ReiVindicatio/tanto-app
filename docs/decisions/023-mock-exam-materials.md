# 模試の材料は法務省の「短答式試験の結果」と受験案内から読み取り、読めない資料は埋めない（2026-10-24）

> 決定の記録。**以後編集しない。**手順の現行版は `pipeline/exam_info.py` の冒頭。T028。

## 決めたこと（設計はユーザーと合意。司法 H23〜H26 と、読めない資料の扱いは実装中に分かったことで、実装レビューで確かめる）

- 模試の比べる相手（合格点・科目ごとの平均点・得点別人員）と試験時間は、法務省の「短答式試験の結果」（年度ごと）と受験案内の PDF から読み取る。PDF は `data/raw/<試験>/資料/<年度>/` に置き、取得元を `sources/manifest.json` に記録する（`pipeline/exam_info.py --fetch`）。読み取った値は `data/exams/short_answer.json`（検算つき）
- 試験時間は、法務省のサイトに残っている受験案内が R08 だけ（2026-10-24 確認）なので、どの年度も R08 の時間で解く。画面にそう書く
- 司法試験の H23〜H26（公法系・民事系・刑事系の短答）は、試験時間の資料がないので模試にしない
- テキスト層が壊れている PDF は AI や OCR で埋めず、その比較だけ出さない：予備 H29 の結果（文字化け）、司法 R07 の科目別の得点別人員調（文字が図形）
- 予備の合格点は一般教養科目を含む合計に対する点なので、法律科目だけの得点とは直接比べず、平均点と比べ、合格点の得点率は参考として注記つきで並べる
- 模試の答えは肢ごとに記録しない（「問で解く」と同じ。設計 §3.7）。点数だけ端末に残す（`tanto.mock.v1`）

## 理由

- 素材は法務省の公開資料だけ（CLAUDE.md 🔴1）。合格点・時間を記憶で書かない
- 読めない資料を推測で埋めると、比べる数字そのものが誤りになりうる
