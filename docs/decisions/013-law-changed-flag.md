# 出題後の改正で正誤が変わる肢は、要確認（law_changed）として肢カードから外す（2026-10-19）

> 決定の記録。**以後編集しない。**

## 何が起きたか

民法 R03 問13エ（婚姻の届出から1か月後に生まれた子の父子関係の否定）の解説を書く際、出題時点の772条では嫡出推定が及ばず公式の正解は×だが、2024年4月施行の改正で772条1項後段（婚姻成立後に生まれた子も夫の子と推定）が設けられ、現行法では○になることが分かった（`pipeline/revisions.py` で出題時点の版と比べて確認）。

## 決めたこと（ユーザーと合意）

- `truth_at_exam` は変えない（禁止事項2）
- `data/review/flags.json` に `kind: "law_changed"` で記録し（決定008の仕組みをそのまま使う）、**肢カードから外す**。問で解くには残し、「要確認：出題後の法改正で正誤が変わる肢です。○×は出題時点の正解です」と出す
- 解説は、出題時点の結論（公式の○×）と現行法での結論の両方を書く（`stated_truth` は出題時点の結論）
- 現行法での○×を別に持つかどうかは T004・T013 で決める

## 理由

- 出題時点の○×のまま肢カードで繰り返し覚えると、現行法と逆の知識が身につく
- 一方、問で解く（本番形式の再現）では公式の採点が正しい
